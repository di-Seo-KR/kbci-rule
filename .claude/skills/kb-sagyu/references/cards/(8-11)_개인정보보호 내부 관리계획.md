# (8-11) 개인정보보호 내부 관리계획 — 요약 카드
- 소관: IT운영부 정보보호팀 / 시행: 2026. 8. 14.(개정-2026-0○○, 문서번호 미기재) / 조문 수: 47조까지(가지조문 제6조의2·제7조의2·제8조의2·제15조의2·제16조의2·제23조2·제23조의3 포함 54개조, 11장) / 별표·서식: 16건(서식 11, 첨부 3, 샘플 2)
- 한 줄 요약: 『개인정보보호법』 제29조에 따른 내부 관리계획. 개인정보 보호 조직, 개인정보처리시스템의 기술적·관리적·물리적 보호조치(접근권한·비밀번호·암호화·접속기록·파기), 자체점검·교육, 유출 대응, CCTV·녹취(STT.TA)·생체정보·재택 원격접속 운영 기준을 정한다. 본문에 경영전략부장 역할이 많지만 소관은 IT운영부 정보보호팀.

## 1. 핵심 규칙
- 적용: 온라인·오프라인(서면, 전화, 팩스, CCTV 등)으로 처리되는 개인정보와 이를 취급하는 내부 임직원 및 외부업체 직원 (제2조). 개인정보취급자에는 정규직 외 임시직, 위임직, 도급직, 파견근로자, 시간제근로자 등 포함, "수행하였던 자"도 포함 (제8조①).
- 수립·승인: 개인정보 보호책임자가 수립·수정 시 **대표이사 내부결재 등 승인**, 수정 이력 관리 (제4조⑤). 이행 실태 연 1회 이상 점검 (제4조⑥). 전 임직원에게 알리고 열람 가능하게 비치 (제5조).
- 조직: 개인정보 보호책임자(CPO) = 고객정보관리를 담당하는 주무부서의 담당 임원 (제6조의2). 개인정보보호관리자 = 각 부점장 (제3조제7호). 개인정보 보호 조직 = 보호책임자, 담당부서(팀), 취급자, 개인정보협의회 (제6조②). 주요 의사결정은 정보보호위원회에서 심의·협의 (제8조의2).
- 접근권한: 최소 범위 차등 부여, 보안서약서 년 1회 이상 징구 (제9조①). 인사이동 시 지체 없이 변경·말소, **6개월 이상 접속기록 없는 자 권한 말소** (제9조②). 권한 부여·변경·말소 기록 최소 5년 보관 (제9조③). 취급자별 1개 계정, 공유 금지 (제9조④).
- 비밀번호: 영문자·숫자·특수문자 중 세가지 조합 최소 8자리 이상 또는 두가지 조합 10자리 이상 (제10조①). 개인정보처리시스템 및 업무용PC 변경주기 **3개월 이내** (제10조②). 입력 오류 최대 5회 시 접속 차단, 본인 확인 후 재부여·초기화 (제10조④). 시스템마다 관리자 비밀번호 다르게 (제10조③).
- 접근통제: IP 제한·유출 시도 탐지 (제11조①), 외부에서 접속 시 인증서·보안토큰·일회용 비밀번호 등 안전한 인증수단 (제11조③), 취약점 점검 연 1회 이상 (제11조④), 일정시간 미사용 시 자동 접속 차단 (제11조⑤).
- 암호화 저장 대상: 주민등록번호, 여권번호, 운전면허번호, 외국인등록번호, 신용카드번호, 계좌번호, 생체인식정보 (제12조①). PC·모바일·보조저장매체 저장 시 DRM 등으로 암호화 (제12조②). 인증정보는 저장·송수신 시 암호화, 비밀번호는 일방향 암호화 (제12조⑥). DMZ·내부망에 고유식별정보 저장 시 암호화 (제12조⑦).
- 마스킹: 주민등록번호는 뒤 6자리 마스킹, 기타 항목은 [첨부 제2호] 그룹 개인정보 마스킹 표준 (제12조④).
- 접속기록: **최소 3년 이상 보관**(2026.8.14. 개정) (제13조①), 월 1회 이상 점검, 다운로드 확인 시 사유 반드시 확인 (제13조③).
- 보안프로그램: 자동 업데이트 또는 일 1회 이상 업데이트 (제14조②). 감염 시 [첨부 제1호] 대응절차 (제14조④).
- 파기: 불필요하게 된 때부터 **5일 이내** 파기 (제15조의2①). 방법 — 완전파괴(소각·파쇄), 전용 소자장비, 초기화·덮어쓰기 (제15조의2②). 종이문서를 외부 전문업체로 파기하면 [별지서식 1-3] 체크리스트 작성 + 파기확인서 징구·보관 (제15조의2⑤, 2026.8.14. 신설).
- 출입 보안: 적용 범위는 본점 모든 출입문 및 영업점 메인 출입문 (제16조의2①). 물리보안담당자가 출입카드(모바일 포함) 발급·회수 (제16조의2③). 출입(방문)증 불출·반납 시 「열쇠관리지침」 제8조에 의거 관리대장 기록 (제16조의2⑤). 보안사고 시 지체 없이 개인정보 보호책임자 및 경영전략부장에게 보고(중요시설·장비 화재·파괴사고는 IT운영부장 추가 보고) (제16조의2⑥).
- 공용PC(인터넷PC, 스캐너PC 등): 취급자를 개인정보관리책임자로 지정, 패스워드는 개인정보관리책임자가 관리·정기 변경 (제17조).
- 자체점검 (제19조): ①보호책임자 → 각 부·지점, 매년 2회 이상 ②개인정보보호관리자 → 소속 부·지점, 매월 1회(보안의 날), [별지서식1-1]·[별지서식1-2] ③보호책임자 → 개인정보처리 위탁업체, 반기 1회 이상, 현장점검 또는 서면점검.
- 교육: 연간 교육계획 매년 1월말까지 수립 (제21조①), 개인정보취급자 대상 연1회 이상 실시 (제22조①).
- 유출 대응: 취급자는 인지 시 [별지서식6] 정보 유출 보고서를 보호책임자에게 제출 (제23조2①). 정보주체 통지는 **72시간 이내** (제23조2②). 개인정보 보호위원회 또는 한국인터넷진흥원 신고는 ①1천명 이상 ②민감정보·고유식별정보 ③외부 불법 접근에 의한 유출의 경우 72시간 이내 (제23조2⑤). 대응절차는 [고객정보유출 비상대응매뉴얼] (제23조2④).
- CCTV(제8장): 영상정보관리책임자 = 본사 경영전략부장, 각 점포 고객정보보호관리자 / 접근권한자 = 본사 총무담당자, 각 점포 고객정보관리책임자 (제3조제14호·제14-2호). 운영·관리방침 홈페이지 게시 (제24조), 안내판 설치 (제27조), 녹음기능 사용 불가·임의 조작 금지 (제25조②). 보관기간은 방침에 명시한 기간, 산정 곤란 시 수집 후 30일 이내 (제29조). 목적 외 이용·제3자 제공 시 [별지서식2] 기록 (제30조①). 열람·제공은 입회자(본사 경영전략부장 / 각 점포 지점장·영업소장·센터장·출장소장) 입회 하에 (제30조②). 열람 청구는 [별지서식3] (제32조②).
- 녹취·STT.TA(제9장): 책임자 = IT운영부장 (제34조). 녹취 시 반드시 상대방에게 고지 (제36조). 녹취 자료 **3년간 저장 후 지체 없이 파기** (제37조①). 외부 반출 금지 (제37조②). 열람·제공은 통합전산시스템 전산작업의뢰 → 관리부서장 승인, [별지서식4] 기록, 고객정보관리책임자 입회 (제38조①~③).
- 생체정보(제10장): [별지서식7] 동의 + [별지서식8] 관리대장 (제42조①). 목적 달성·보유기간 만료·동의 철회 시 동의서와 생체정보 지체 없이 파기 (제44조). 생체정보 관리책임자 = 본사 경영전략부장/총무담당자, 지점·센터 지점장/열쇠담당자 (제3조제18호).
- 원격접속(제11장): 재택근무자에게 외부용 단말기 제공, 본인 업무용 단말기만 원격접속 (제45조①), 서약서 징구 (제45조②). 원격접속 기록 1년이상 보관, 이중 인증, 5회 이내 인증 실패 시 차단, 유휴시간 15분 이내 경과 시 차단, 화면캡쳐·출력 차단, 파일 송수신 차단, USB 차단 (제46조). 공공장소 원격접속 금지, 종료 시 즉시 반납 (제47조).

## 2. 예외·단서·생략·위임·준용
- (CPO 지정) 정보보호 최고책임자(CISO)가 그 역할을 **대리**할 수 있다 (제6조의2).
- (6개월 미접속자 권한 말소) 업무목적으로 경영전략부장 요청 시 일정기간 접근권한 유지 가능 (제9조② 단서).
- (외부 접속 시 안전한 인증수단) 정보주체는 제외. 이용자가 아닌 정보주체의 개인정보를 처리하는 시스템은 가상사설망 등 안전한 접속수단 또는 안전한 인증수단 적용 가능 (제11조③ 단서).
- (접속기록 보관) 정보주체의 접속은 제외 (제13조①).
- (마스킹) 예외는 업무수행에 필요한 최소한의 정보에만, **정보보호위원회 사전심의**로 필요성·타당성 판단 (제12조⑤).
- (인증정보 암호화) 비밀번호 저장은 복호화되지 않도록 일방향 암호화 (제12조⑥ 단서).
- (보안 업데이트 즉시 실시) "정당한 사유가 없는 한" (제14조③).
- (5일 이내 파기) "정당한 사유가 없는 한" (제15조의2①). 일부만 파기하는 경우 전자파일은 삭제 후 복구·재생 방지 관리, 서면 등은 마스킹·구멍 뚫기 (제15조의2③). 기술적 특성으로 현저히 곤란하면 복원 불가능하게 처리(익명화) (제15조의2④).
- (출입) 상행위 목적, 해당 부점의 출입제한 요청, 물리보안담당자가 위해하다고 판단하는 경우 출입 제한 가능 (제16조의2④).
- (위임) 보호조치의 구체적 방법·세부절차는 『정보보호 관리지침』에서 정하는 바에 따른다 (제18조).
- (위탁업체 점검) 당사가 재위탁업체를 관리하는 경우 원 위탁자가 동일 재위탁업체를 정기점검했으면 그 결과 활용 가능 (제19조③5호, 2026.8.14. 신설).
- (유출 통지 72시간) "특별한 사유가 없으면" (제23조2②). 제2항에도 **불구하고** 연락처를 알 수 없는 등 정당한 사유가 있으면 홈페이지 30일 이상 게시로 통지를 **갈음** (제23조2③).
- (유출 신고 72시간) 천재지변 등 부득이한 사유면 사유 해소 후 지체 없이 신고 가능; 유출 경로가 확인되어 회수·삭제 등으로 권익 침해 가능성이 현저히 낮아진 경우 **신고하지 않을 수 있다** (제23조2⑤ 단서).
- (개인영상정보 목적 외 이용·제공 금지) 예외 5가지: 동의, 다른 법률 특별 규정, 급박한 생명·신체·재산 이익, 가명처리한 통계작성·과학적연구·공익적 기록보존, 공중위생 등 공공 안전 (제28조①).
- (영상정보 보관기간 만료 시 파기) 다른 법령에 따라 보존해야 하는 영상정보는 분리 저장·관리 (제29조① 단서).
- (영상 열람 요구) 제3항에도 **불구하고** 법 제35조제4항 각 호에 해당하면 제한·거부 가능, 10일 이내 서면 등으로 사유 통지 (제32조④). 열람 대상은 본인이 촬영된 영상 및 급박한 생명·신체·재산 이익에 필요한 영상에 한함 (제32조①).
- (녹취 고지) 녹취시스템의 자동음성 메시지로 **대신**할 수 있다 (제36조).
- (녹취 3년 후 파기) 업무 위임기관의 파기 요청 시에도 지체 없이 파기 가능; 보관 필요 시 녹취시스템 책임자 승인 하에 서버 보관·승인 후 열람 (제37조① 단서).
- (녹취 외부 반출 금지) 범죄수사, 재판수행 및 민원처리 등 증거자료에 필요한 경우 예외 (제37조② 단서).
- (STT·TA정보) 녹취 정보와 동일하게 제37조①~③ 적용. 단, TA정보 중 분석·통계 용도로 개인정보에 해당하지 않으면 **적용하지 아니함** (제37조④).
- (녹취 열람 절차) 권한 있는 자가 연계된 개인정보처리시스템으로 열람하고 관리대장 항목을 전산으로 생성·관리하면 제38조①(전산작업의뢰·승인)과 ③(입회·수기 기록)을 **적용하지 아니함** (제38조④).
- (재택 원격접속) 장애·재해·파업·테러 등 긴급상황 대응을 위한 IT직원의 업무시스템 직접접속 및 개인소유 외부용 단말기 사용은 예외 (제45조① 단서).
- (참고 규정) 권고 암호 알고리즘은 한국인터넷진흥원 [개인정보의 암호화 조치 안내서]에 따라 [첨부 제3호] 참고 (제12조⑧).

  - 「고객정보관리 지침」(8-5): 제3조제5~8호가 각 책임자를 그 지침의 직책에 대응시킴. 제15조(CPO = 주무부서 담당 임원, CISO 대리 가능; "정보보호 최고책임자"를 "고객정보 보호책임자"라 칭함), 제16조(각 부점장 = 고객정보보호관리자), 제17조(고객정보관리책임자, 사무분담 지정) 실재 확인.

  - 「고객정보관리 지침」 제5조③: 고정형 영상정보처리기기 설치·운영은 이 계획 제8장을 따름. 제5의3조③: 민감정보·고유식별정보 안전성 확보조치 세부 기준은 이 계획 제4장을 따름.
