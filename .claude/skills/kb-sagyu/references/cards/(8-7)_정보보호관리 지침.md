# (8-7) 정보보호관리 지침 — 요약 카드
- 소관: IT운영부 정보보호팀 / 시행: 2026. 7. 1.(개정-2026-021) / 조문 수: 89개조(10장) / 별표·서식: 17건(별표 2, 서식 15)
- 한 줄 요약: 「정보보호규정」의 세부 지침으로 정보보호 조직·역할, 정보자산 관리·위험평가, 인력보안(서약서), 교육, 외부인력 보안, 사용자(PC·패스워드·보조기억매체·메일·모바일) 보안, 보안점검·감사, 침해사고 대응, 재해복구를 정한다.

## 1. 핵심 규칙
- **적용 대상**: 조직·구성원·외부직원 등 모든 인력과 모든 정보자산(제2조). "사용자"는 임직원(계약직원 포함)+외부인력(제3조31호).
- **조직**: 정보보호위원회·정보보호 주관부서 구성, 부점별 정보보호 담당자 지정(제4조①). 정보보호 최고책임자는 주무부서의 장 또는 임원으로 지정(제6조①). 정보보호 관리자(제7조)·담당자(제8조)·정보시스템 관리자=IT업무담당 부서장(제10조①)·정보시스템 담당자(제11조) 역할 열거. 정책·지침의 해석은 정보보호 관리자(제7조②13호).
- **정보자산**: 12종 분류(제13조①), 중요도는 기밀성·무결성·가용성 **3등급**(제14조), 자산 현황 **연 1회 이상** 조사(제15조④). 도입·용도 변경 시 정보시스템 관리자 검토·승인 + 정보보호 관리자에게 보안성검토 요청(제16조④). 폐기 시 내역 기록, 전자파일 영구 삭제·그 외 파쇄·소각(제17조①②).
- **위험관리**: 위험관리 계획 **연 1회** 수립·정보보호 최고책임자 보고(제18조①), 위험평가 **연 1회 이상**(제19조①), 목표 위험수준(DoA)은 정보보호 최고책임자 승인 필수(제19조⑤), 이행계획 진행 경과와 DoA 초과 위험수용은 **대표이사 보고**(제20조③⑥).
- **직무분리**: 프로그래머/업무운영자/정보시스템 운영자/감사자/외부인력 간 분리(제22조①). 주요 직무자 지정·최소 인원·변경·퇴사 시 즉시 해제(제22조③~⑤).
- **서약서**: 입사 시 [별지1] 서약서, [별지2] 정보보호서약서, [별지2-1] 고객정보보호서약서, [별지2-2] (입사)비밀유지서약서(제23조①). 외부AI서비스 업무 활용 시 [별지2-4] AI서비스이용 보안서약서(제24조④). 퇴사 시 [별지2-3] (퇴사)비밀유지서약서 + 자산 반환·권한 말소 점검기록 보관(제25조). 외부인력은 [별지2]+[별지3](제33조②, 교체 인력도 동일 — 제34조①②), 계약 종료 시 [별지3-1](제38조③).
- **교육**: 교육계획 **연 1회 이상** 수립·보고(제27조①), 전 직원 **연 1회 이상** 교육(제29조①), 외부인력 **연 1회 이상**(제34조⑤). 전자화관계자 연간 최소 교육시간: 전자화작성자 **6시간**, 시스템관리자 **8시간**, 전자화검사자·전자화책임자 **12시간**(제31조①).
- **외부업체 계약**: 계약서에 보안요구사항 7가지 명시(제33조①), 개발 위탁 시 5가지 추가(제33조③). 제공 자료에 고객 개인정보 불포함(제34조⑦). 자료는 회사 내에서만 열람(제34조⑩). 전산장비 반입은 「물리보안지침」에 따라 반입신청(제34조⑬).
- **PC**: 지급받은 업무용 PC만 사용, 개인 PC 원칙 금지(제41조①). 화면보호기 **10분 이하**(제41조③3호). 반출·입 및 사용자 변경 시 하드디스크 포맷 + [별지4] 관리대장 기록(제40조①, 제43조②). 불용 처리 시 하드디스크 소각·파쇄·용해, 위탁 시 폐기업체 보안서약서·증적 제출, [별지4-1] 확인서 작성(제43조③④). PC 정책 이행 **연 1회 이상** 점검(제41조⑦). 중요단말기는 외부 반출·인터넷·그룹웨어·메일 금지, 악성코드 매일 점검(제42조②).
- **패스워드**: **최소 3개월마다** 변경, 이전과 동일 금지, 자동 저장 금지, 초기 패스워드 즉시 변경(제45조③~⑥), 작성규칙은 [별표 5](제45조⑦).
- **백신·패치**: 일 1회 이상 업데이트, 매일 검사(제46조②③). 침해 의심 시 즉시 정보보호 관리자에게 신고(제46조④).
- **소프트웨어**: 회사 제공 업무용만 사용, 특정 SW 필요 시 정보보호 관리자 승인(제44조①③).
- **메일·메신저**: 업무 목적만, 회사 허가 메신저 외 금지, 중요 정보 기재 금지(제50조①④⑤).
- **보조기억매체**: 원칙적 사용(읽기/쓰기) 금지(제51조④). [별지6]·[별지7] 등재 후 사용·배포, 목적 종료 시 회수(제51조⑤). 부점은 **월 1회 이상** 수량·보관상태 점검([별지8]), 반·출입 시 [별지9] 기록(제51조⑧).
- **모바일**: 개인 기기는 인가된 모바일 오피스 앱으로만 접속, 화면 캡쳐 금지 등(제54조). 업무용 기기 분실·도난 즉시 신고(제55조⑧).
- **점검·감사**: 보안점검 **연 1회 이상**(제56조①), 정보보안 자체점검 **매분기 1회**(제59조), 관리체계 점검·생활보안 점검·취약점 점검·컴플라이언스 점검 각 **연 1회 이상**(제58조①, 제60조①, 제61조①, 제62조①). 보안감사는 제3자 수행 원칙, 계획은 정보보호 최고책임자 승인(제64조①④).
- **침해사고**: 4유형(서비스 중단, 변조·수정, 악성코드 감염, 중요정보 유출)(제67조), 심각도 4단계 비상·위기·경고·주의와 보고선(비상·위기=정보보호 최고책임자, 경고·주의=정보보호 관리자)(제68조). 접수 시 [별지 11] 보고서(제70조③), [별지 10] 목록 기록(제77조⑥), 기록은 '대외비'로 **3년간** 보존(제77조⑦). 사고대응팀은 [별표 12]대로 구성(제72조①). 대응 훈련 **연 1회 이상**(제78조②).
- **재해복구**: 비상대책위원회 운영·대표이사 보고(제79조①, 제86조③). 위기수준 = 전산시스템 마비 **24시간 이상 심각 / 12시간 이상 경계 / 6시간 이상 주의 / 3시간 이상 관심**(제84조). 모의훈련 **연 1회 이상**(제88조①).

## 2. 예외·단서·생략·위임·준용
- (제4조③) 직무 분리가 어려우면 **정보보호 최고책임자 승인** 하에 타 업무 담당자 겸임 가능(정보보호 조직). (제22조②) 직무분리가 어려우면 **대표이사 승인** 하에 겸직 가능 — 단, 모니터링 강화 등 보호대책 강구.
- (제5조①) 정보보호위원회 구성·역할은 「정보보호위원회 지침」에 위임. (제9조②) 부점 정보보호는 「고객정보관리 지침」에 위임.
- (제10조③, 제16조②) 정보시스템 관리자·정보자산 관리자는 담당자를 지정해 관리 권한 **위임** 가능. (제21조②) 인사업무담당 부서장은 인사보안 실무를 정보보호 담당자에게 위임 가능.
- (제17조④) 보존기간 경과 자산 폐기 분량이 많으면 주무부서 또는 폐기대행업체가 취합·폐기 가능(계약서에 절차 명시·확인 기록 — 제17조⑤).
- (제18조②) 위험관리 계획은 연간 정보보호계획에 포함 수립 가능. (제19조① 단서) 중요 시스템 도입·개발 등 필요 시 **약식 위험평가** 가능.
- (제26조②) 법규·내규 미준수 등은 「신용정보관리 지침」 제40조에 따라 징계. (제26조③, 제66조④) 그 외 포상·징계는 「인사규정 시행지침」.
- (제28조②) 계약기간을 고려해 외부직원을 교육대상에서 **제외** 가능(계약부서에 자체 교육 요청). (제28조③) 불참자는 온라인 등 별도 교육.
- (제31조③) 전담기관 전문교육과정 이수 시 **다음 연도 교육 면제** 가능.
- (제33조④) 외부업체 계약 시 「개인정보보호 내부 관리계획」의 "개인(신용)정보 처리업무 위탁약정서"를 포함해 체결할 수 있음.
- (제34조⑤) 외부업체가 자체 교육한 경우 결과를 요청해 확인. (제34조⑧ 단서) 외부인력의 입력·정정거래 금지 — 불가피하면 정보보호 관리자 승인. (제34조⑪ 단서) 산출물 외부 반출 금지 — 불가피하면 정보보호 관리자 승인.
- (제41조③10호 단서) PC에 고객정보 등 보관 금지 — 불가피하면 문서보안 솔루션 암호화 + 보관사유·기간·관리 비밀번호 지정. (제41조④ 단서) 공유 폴더 금지 — 필요 시 특정 폴더에 권한·패스워드 설정. (제41조⑥) 인증되지 않은 PC는 회사 보안소프트웨어 설치 후 내부망 접속.
- (제44조④) 소프트웨어 규정은 서버·통신장비·기타 컴퓨터에도 적용.
- (제45조② 단서) 공용 패스워드 금지 — 불가피하면 사전 승인 + 보호대책. (제45조⑦) [별표 5] **준용**.
- (제49조④) 공공장소 PC로 회사 시스템 접속 금지 원칙 — 긴급 시 자료 다운로드 금지·로그아웃 없이 이석 금지.
- (제51조④ 단서) 보조기억매체 사용 금지 — 업무상 반드시 필요하면 사전 등록 후 사용. (제51조⑥2호) 중요자료 저장 금지 — 불가피하면 부점 정보보호 관리자 사전 승인 + 암호화.
- (제52조④2호 단서) 중요정보 문서 복사 금지 원칙 — 업무상 필요 시 최소 부수.
- (제54조③) 개인 모바일기기 세부사항은 「물리보안지침」.
- (제56조⑤) 외부 전문업체 점검 시 그 결과보고서로 정보보호 최고책임자 보고를 **대체** 가능. (제61조② 단서) 취약점 점검 기준은 자산 특성에 따라 자체 수정 가능. (제61조③1호) 수시 점검 대상에서 단순 용량 증설 등 **제외**.
- (제64조②) 별도 감사조직 구성이 어려우면 정보보호 주관부서가 보안감사 수행 가능. (제64조⑤ 단서) 증거 인멸 우려 시 감사계획 **사후 통지** 가능.
- (제68조④) "주의" 등급은 침해사고의 대상에서 **제외**(모니터링으로 관리).
- (제73조③) 통지·신고 세부는 「고객정보 유출대응 매뉴얼」·「전자적침해사고 대응 매뉴얼」. (제77조③) 외부기관 보고는 정보보호 최고책임자 인가.
- (제79조③) 재해복구 세부는 『재해복구 운영관리기준』. (제80조②) 장애로 재해에 준하는 피해가 나면 재해로 봄 — 단, 일시적·부분적 장애 **제외**.
- (제89조②) 비상대응교육을 연간 정보보호교육에 포함하면 별도 교육 **생략** 가능.
- (부칙 2026. 1. 1.) 이 지침 시행으로 『공인전자문서센터 정보보호업무지침』과 『정보보안관리지침』 폐지.

## 3. 다른 사규와의 연결
- 이 사규 → 다른 사규 (실재 확인)
  - 「정보보호위원회 지침」(3-4): 실재. 제2조 구성(의장 정보보호최고책임자).
  - 「고객정보관리 지침」(8-5): 실재하나 "부점별 정보보호 담당자"라는 명칭은 없고 제16조는 각 부점장을 "고객정보보호관리자"로 지정 — 명칭 불일치.
  - 「신용정보관리 지침」(8-6) 제40조(제재): 실재, 양정은 그 지침 [별표 제2호].
  - 「인사규정 시행지침」(6-10): 실재(제18조~제23조 포상, 제24조~제29조 징계, [별표 제2호] 징계양정 기준).
  - 「물리보안지침」(8-9): 실재. 제13조(통제구역 내 장비 반·출입 관리), 제14조(통제구역 내 모바일기기 및 보조기억매체 관리). 본문은 조번호를 특정하지 않음.
