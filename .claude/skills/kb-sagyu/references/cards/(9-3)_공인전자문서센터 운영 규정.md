# (9-3) 공인전자문서센터 운영 규정 — 요약 카드
- 소관: 전자문서사업부 / 시행: 2026. 6. 1.(개정-2026-016) / 조문 수: 제1조~제85조(6장) 중 제82조·제83조 삭제, 현행 83개조 + 부칙 8건 / 별표·서식: 별첨 10건(+본문 내 표 다수)
- 한 줄 요약: 공인전자문서센터("센터")의 물리 보안·암호화·키관리·네트워크·서버·변경관리·응용시스템 보안·백업·비상대응(BCP)·침해사고·내부통제 기준과 담당 조직(전자문서사업부·IT운영부·DT개발부·정보보호 소관부서)의 직무를 정한다.

## 1. 핵심 규칙
### 물리 보안·출입·자산
- 보안구역은 센터 시스템실, 백업실, 운영실. (제3조제2항) 보안구역 내에는 CCTV 등 영상촬영 설비와 저장시설 구비. (제6조제5호)
- 출입통제: 출입카드 또는 생체 인식 병행 인증, 접근 권한 정기 재심사, 출입 내역은 전자적 매체 또는 수기 대장 기록, 잠금장치 접근 내역은 열쇠관리 대장 기록. (제7조제1항)
- 센터 운영자는 김포 및 여의도 전산센터의 물리적 접근방지 정책·지침을 분기별 1회 이상 점검해 부서장에게 보고. (제7조제1항제8호) 같은 센터의 운영지침·비상사태 대응 지침도 분기별 1회 이상 점검·보고. (제74조제3항)
- 통제구역 작업(설치·폐기·유지보수): 작업신청 시 IT운영부, 정보보호팀, IDC 보안관제팀의 검토·승인. 작업 기록에 일자·시간·목적·내용·업체 및 담당자명·검토자 승인자 포함. (제7조제2항)
- 자산 반출·반입: 해당 부서장 승인 없이 사외 반출·사내 반입 불가([별첨 제3호] 자산 반출입 신청서). 정기 반복 반출입(백업미디어 소산 등)도 승인 필요. (제8조제1항~제4항)
- 보호구역에 모바일 기기·보조저장매체 반출입 시: 보호구역 출입통제 책임자 사전승인, 반출입 관리대장 기록, 보안 점검, 내역 주기적 점검. (제8조제6항)
- 시스템실: UPS는 정전 시 30분 이상 전원 공급(제9조제2항제1호), 항온항습·화재 경보/진화 설비, 통제구역 표식·출입관리대장. 출입은 보안관리자의 사전 출입허가, 비자격자는 출입관리대장 기록 및 동행 자격자 확인 서명([별첨 제5호]). (제9조·제10조)
- 설비 설치 높이: 시스템·네트워크 설비 바닥에서 30cm 이상, 콘센트 등 전원접속장치 10cm 이상. (제11조제1항제4호·제5호)
- 유지보수 정기점검: 유지보수 계약서에 따라 매월 1회 또는 2회 기준. (제12조제4항제1호)
- 저장장치 파기: 물리적 파기 또는 표준삭제보다 안전한 덮어쓰기. (제13조)

### 암호화·키
- 암호화 방식은 과학기술정보통신부·KISA '암호 알고리즘 및 키 길이 이용 안내서' 권고 국내 암호 알고리즘 기준 이상. (제15조제1항) 본문 표: 센터 보관 전자문서 SEED, 개인정보·고유식별정보 AES256, 비밀번호 SHA256+SALT 일방향 해쉬, 인터넷 구간 개인정보 TLS 1.2 이상, 송수신 문서·메시지 SSL/TLS·양자내성암호화, 메타정보 RSA, 무결성 정보 SHA256.
- 개인정보·고유식별정보를 DMZ 또는 내부망에 저장하려면 위험도 분석·안전성 확보 조치 검토 후 부서장 승인. (제15조제2항)
- 키 생성·파기는 [별첨 제8호] 암호화키관리대장에 기록. (제16조제3항, 제18조제4항) 백업 키 저장 위치는 암호키관리 담당자만 접근. (제17조제1항)
- 키 파기 사유: 인증서 유효기간 만료 / 인증서 폐지 / 전자서명 생성키 변조. 업무 담당자가 주관부서장 또는 보안관리자와 함께 완전 파기, 백업 키·개인 식별번호도 파기. (제18조)

### 네트워크·서버
- 침입차단시스템은 Inbound·Outbound 모두 Deny All 후 필요한 경로만 단계적 허용(제22조제6항), 이중화(제24조제3항). 정책(Rule set) 변경은 보안 담당자 승인 + [별첨 제2호] 의뢰서. (제25조제1항)
- 침입탐지시스템 로그파일 매일 분석. (제26조제2항) 시각수신장치(NTP)는 장애 시 24시간 이내 복구. (제27조제4항)
- 네트워크 사용량 수요 예측 보고 연 1회 이상. (제23조제4항)
- 계정 등록: [별첨 제1호] 절차서에 따라 신청, 담당 부서장 결재. 퇴직·전출 시 관련 부서장의 계정 반납 확인. 패스워드 변경 최소 3개월에 1회 이상. (제29조)
- 로그 점검: 주요 서버 관리자 매일 1회 이상(제30조제3항), 센터 운영자는 주요 시스템 로그를 월 1회 이상 점검해 부서장 보고(제30조제9항).
- 기록 보관 2년 이상: 시스템 접속기록, 이용자 등록 정보 변경·접속기록, 전자문서 관리 정보, 증명서 관리 정보 및 각 점검 기록. 월 1회 이상 점검·부서장 보고, 개인정보 다운로드 발견 시 사유 확인. (제31조)
- DB: 계정·권한은 내부 결재, 스키마·데이터의 수정·삭제는 정보보호 소관부서장 및 IT운영부서장의 결재. (제32조제2항·제4항)
- 취약점 진단 연 1회 이상, 결과·보완 조치를 담당 부서장 및 대표이사에게 보고. (제35조·제36조)
- 인력: [별첨 제9호] 자격분야·경력분야 요건을 모두 갖춘 인력 6명 이상 항상 유지, 임원·직접 수행 직원의 결격사유 확인, 신고 인력 변동 시 재신고, 직무교육 연 1회 이상. (제38조)
- 직무 구분(제40조제1항): 업무 담당자=전자문서사업부(소관부서장이 업무 관리자) / 인프라 담당자=IT운영부(IT운영부서장) / 서비스운영 담당자=IT운영부서 / 개발 담당자=DT개발부(DT개발부서장) / 정보보호 담당자=정보보호 소관부서. 인프라 담당자는 시스템운영일지를 매일 주무부서장에게 보고(제7호).

### 변경관리·응용시스템
- 변경 절차: 변경요청 등록 → 계획(변경내역 검토서) → 변경 전 모듈 보존·롤백 플랜 → 테스트 → 합의·운영책임자 최종 승인 → 적용·결과서 → 사후리뷰. (제45조)
- 서비스·프로그램 추가·삭제는 담당 부서장 승인, 서버 프로세스 명세서 기록, 월 1회 점검·보고. (제46조)
- 패치: 제조사 패치 버전 확인 매월 1회, 작업 계획서(비상 복구 계획 포함) 부서장 승인, 사전 백업. (제50조)
- 응용시스템 이관: 변경신청서에 보안 테스트 결과를 첨부해 보안 관리자 승인 후 운영 적용. (제57조제1항) 특별 권한 사용자 권한 적절성 분기 1회 검토. (제58조제1항)

### 백업·비상대응
- 백업 보관(제71조): OS·데이터 60일, DB 60일(주 1회 Full + Daily Archive), 소스데이터 60일, 로그 데이터·시스템 로그(Event LOG)·감사 기록 5년. Worm 스토리지는 동일 센터 1대·원격지 1대.
- 백업 결과는 백업관리대장([별첨 제4호]) 기록, 월 1회 책임자 보고(제71조제8호다목). 백업 감사 최소 분기당 1회(제72조).
- 복구 목표: RPO 24시간 이내, RTO 6시간 이내(인프라 복구 3시간 + 서비스 복구·확인 3시간). 우선순위는 [별첨 제10호]. (제71조제9호)
- 위기수준: 심각 24시간 이상 / 경계 12시간 이상 / 주의 6시간 이상 / 관심 3시간 이상 마비. (제76조) "심각" 또는 "경계"면 비상 연락망으로 대응 팀 소집. (제78조제1항제5호)
- 위기대응: 탐지 즉시 IT운영부서장 또는 정보보호팀 보고 → 구두 후 서면 보고 → IT운영부서장이 심각도 판단·종료 결정 → IT운영부서장 및 경영진 결과 보고. IT운영부는 상부 감독기관 통보. (제77조·제78조)
- 모의훈련("가용성 테스트" 등) 연 2회 이상, IT운영부서장 보고. (제79조제3호)
- 개인정보 침해사고 교육 연 1회 이상(본문 표: 전 임직원 연 1회, 개인정보취급자 연 2회), 모의훈련 계획·결과는 소관부서장 및 대표이사 보고. (제84조)

## 2. 예외·단서·생략·위임·준용
- 준용: 이 규정에 없는 센터 정보보호 사항은 『정보보호 관리지침』, 『IT인프라 보안지침』, 『물리보안 지침』 준용. (제2조제3항)
- 인가된 경우를 제외하고 보안구역 내 사진·비디오·오디오·저장 장치 사용 불가. (제6조제4호) 부피가 큰 물건은 필요한 경우를 제외하고 보안구역 내 보관 금지. (제5조제4호)
- 통합IT센터·여의도전산센터 이용 시 특례: 해당 인력이 IDC 보안관제팀 역할 수행 가능(제7조제2항 단서) / 방문객 관리 시스템으로 자산 반출입 관리(제8조제5항) / 방문객 관리 시스템으로 출입자 관리(제10조제4호) / 센터 내 디가우징 장비 활용 가능(제13조제3항).
- 센터 보관 정보(고유식별정보, 비밀번호, 생체인식정보 등)의 PC·모바일 다운로드 금지 — 부득이한 경우 부서장 사전 승인과 안전성 확보 조치, 용도 충족 시 지체 없이 파기. (제15조제4항)
- 암호 알고리즘에 보안취약점 발견 시 담당 부서장 승인을 받아 즉시 조치. (제15조제6항)
- 카드등록 신청은 특별한 사유가 없는 한 등록. (제19조제4항)
- VPN 원격진단 원칙 금지 — 불가피한 경우 신청서 작성([별첨 제1호]), 영향도 검토 후 보안관리자 승인. (제22조제5항)
- 침입차단시스템 원격 관리 금지 — 부득이한 경우 보안 관리자 승인 하에 시간 최소화·강력한 인증. (제25조제3항 단서)
- 장기 파견자·휴직자 계정 잠정 폐쇄 원칙 — 부득이하면 유보 사유를 시스템 관리자에게 통보. (제29조제2항 단서) 취약 패스워드 2회 이상 경고 시 일시 계정 폐쇄(잠금) 가능. (제29조제6항제1호)
- 취약점 진단은 필요시 추가 실시 가능. (제35조)
- 준용: 인력운영에 관해 이 규정에 없는 사항은 관계법령, 회사의 관련규정 및 지침 준용. (제38조제1항)
- 근무자는 정(식)직원 — 단, 회사 방침에 따라 외부 위탁 직원 활용 가능, 이 경우에도 "회사의 인사복무규정"에 따른 조치·통제. (제39조 단서)
- 서비스운영(제40조제1항제3호)·개발(제4호)·정보보호(제5호) 업무는 일부를 외부 업체에 위탁 가능.
- 개발 툴(컴파일러·편집기)은 운영 환경 미설치 원칙 — 필요성 인정 시 시스템관리자 요청과 보안 관리자 승인 후 설치. (제44조제2항 단서)
- 변경 테스트가 불가(환경 상이, 단순작업)하면 사유 기재. (제45조제4호나목)
- 긴급장애 시 변경절차 생략: 운영책임자(응용은 운영책임자 또는 개발책임자) 지휘 하에 선 장애복구, 장애보고서로 대체. (제45조제8호, 제47조제9항)
- 단순변경건은 품질 결과서 작성 생략 가능(제47조제5항제2호 단서) / 담당자가 개발파트인 경우 배포승인 절차 생략 가능(제47조제6항제3호 단서) / 7일 경과 시까지 이상 없으면 확인결과서 없이 정상 종결 간주(제47조제6항제5호 단서).
- 패치를 적용하지 않을 경우 보안성 검토 후 부서장 승인. (제50조제8호)
- 테스트에 실 운영 데이터 사용 원칙 금지. (제56조제1항)
- 세션 자동 중단 원칙 — 개발 업무나 시스템 운영상 필요성 인정 시 예외. (제58조제2항제3호 단서)

## 3. 다른 사규와의 연결
- 이 사규 → 다른 사규
  - 「정보보호관리 지침」(8-7), 「IT인프라 보안 지침」(8-8), 「물리보안지침」(8-9): 모두 실재(제2조제3항 준용처, 표기는 다름).
  - 「감사규정」(11-1): 실재. 제14조제2항이 센터·전자화 작업장 감사를 직접 규정.
  - "회사의 인사복무규정"(제39조): 같은 이름의 사규 없음 — 「인사규정」(6-5), 「복무규정」(6-9)이 별개로 존재.
  - 「KB신용정보 전자적 침해사고 대응 매뉴얼」(제81조): 사규 92건 목록에 없음(매뉴얼). 「정보보호규정」 제34조, 「정보보호관리 지침」 제73조도 같은 매뉴얼을 언급.
- 다른 사규 → 이 사규
  - 「정보보호규정」 제27조제3항·제28조제3항: 암호화 및 암호키 관리 세부 사항은 「IT인프라 보안 지침」 및 「공인전자문서센터 운영규정」에 따른다 → 이 규정 제15조~제18조.
  - 「감사규정」 제14조제2항: 센터 및 전자화 작업장은 연 1회 이상 일반감사(직전 감사일로부터 13개월을 넘기지 않음), 감사역 또는 외부 보안 감사기관 전문 감사자가 감사.
  - 「직제규정」 제15조: 전자문서사업부 분장 — 공인전자문서센터 자격 취득 및 업무 추진, 전자화작업장 등록, 공인전자문서중계자, 시점인증.
  - 「직무전결규정」 [별표 제1호] (전자문서) 분야 공통 비고 "[공인전자문서센터 운영규정] 소관부서 전결 사항": 1. 업체 수수료 기준 수립 대표이사 / 2. 기준 변경 집행임원 / 3. 수수료 지급 부서장·본부장(「재무관리규정」 소관부서 합의 필수) / 5. 사고 후속조치 — 보험금 청구 집행임원, 기타 사후관리 부서장·본부장 / 6. 내부정보 보안관리·7. 제보고서 발급: 부서장·본부장.
  - 「전자화문서관리 규정」(9-4) 제12조(센터 Time Server로 시각 동기화), 제15조(센터 발행 타임스탬프, 즉시 이관 시 생략), 제23조·제26조(전자화문서를 센터로 이관), 제8조제4항제4호(센터 연계).
  - 「정보보호관리 지침」 [별표 제12호] 침해사고 대응 조직 및 R&R에 센터 언급.
  - 「사규관리규정」 [별표 제1호]: (9-3) 소관 전자문서사업부(시행일 2026-01-01로 기재되어 현행 2026. 6. 1.과 다름).
- 겹치거나 어긋나는 점
  - 패스워드 변경: 이 규정 제29조제6항 "최소 3개월에 1회 이상" / 「전자화문서관리 규정」 제11조제3항 "90일 이내". 패스워드 구성 규칙(자릿수)은 이 규정에 수치 없음.
  - 통제구역·CCTV 등 물리 기준은 「물리보안지침」 제5조·제9조, 「정보보호규정」 제17조와 중복(준용 관계).
  - 비상대응 주관은 IT운영부서장(제77조·제78조)이고 소관부서(전자문서사업부)장이 아님.
