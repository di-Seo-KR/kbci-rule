< 주요 항목 설명 >
1. 계약관련 개인정보 반출여부 : 실제 개인정보 외부망 반출 “여” 작성
2. 반출 일자 / 반출 대상자 : 계약 대상자 명세를 외부망PC로 반출한 일자 / 대상자
3. 파일명 : 엑셀 또는 워드 명세 파일명   
4. 개인정보 반출 항목 : 외부망PC로 개인정보 반출 항목 
5. 개인정보 반출 항목 : 계약 위탁인력의 전화번호, 주소, 생년월일 외 반출 금지
5. 폐기일자 : 해당 계약정보 명세의 업무용PC(내부망) / 인터넷PC(외부망) 두 PC의 파일삭제 날짜
