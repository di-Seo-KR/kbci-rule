# 화면 캡처 폴더

이 폴더에 화면 캡처 이미지를 넣으면, PPTX 생성 시 각 슬라이드 좌측에 자동으로 삽입됩니다.
(이미지가 없으면 자리표시자가 들어갑니다.)

## 권장 파일명 (화면 ↔ 파일 매칭)

| 화면 | 권장 파일명 |
|------|-------------|
| 01 메인 화면 | `01_메인화면.png` |
| 02 사규 분류로 찾기 | `02_사규분류.png` |
| 03 사규 검색하기 | `03_사규검색.png` |
| 04 사규 상세(본문) 보기 | `04_사규상세.png` |
| 05 사규 캘린더 | `05_사규캘린더.png` |
| 06 공지사항 · 별표/부록 | `06_공지사항.png` |
| 07 법령 검색 (외부 연계) | `07_법령검색.png` |
| 08 본인 인증 / 로그인 | `08_본인인증.png` |

> 파일명이 위와 달라도 괜찮습니다. zip으로 주시면 화면명 기준으로 매칭(필요 시 파일명 정리)하겠습니다.
> 매칭 규칙은 `tools/manual_content.py` 의 각 화면 `image` 값과 연결됩니다.

## 생성 방법

```bash
python tools/build_manual_pptx.py --captures captures \
  --out 사용자매뉴얼/생성본/KB사규관리시스템_사용자매뉴얼.pptx
```
