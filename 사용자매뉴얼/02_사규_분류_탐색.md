# 02. 사규 분류로 찾기 (좌측 트리)

## ① 화면 개요

찾고자 하는 사규의 정확한 이름을 모를 때, 화면 **왼쪽의 사규 분류 트리**를 이용해 주제(편)별로 사규를 찾아볼 수 있습니다.
사규는 `1편`부터 `12편`까지 주제별로 묶여 있습니다.

---

## ② 화면 구성

| 영역 | 설명 |
|------|------|
| 분류 트리 | `1편 정관·이사회` ~ `12편 테스트` 까지 편 단위 목록 |
| 펼침/접힘 (`∨`) | 각 편 오른쪽의 `∨` 클릭 시 하위 사규 목록이 펼쳐짐 |
| 사이드바 접기 (`<`) | 트리 상단의 `<` 로 좌측 영역을 접거나 펼침 |

### 사규 분류(편) 목록

| 편 | 분류명 |
|----|--------|
| 1편 | 정관·이사회 |
| 2편 | 직제·윤리 |
| 3편 | 협의회(위원회) |
| 4편 | 재무·회계 |
| 5편 | 기획·리스크관리 |
| 6편 | 인사·복지 |
| 7편 | 총무·경영지원 |
| 8편 | IT·정보보호 |
| 9편 | 영업 |
| 10편 | 브랜드·ESG |
| 11편 | 감사·준법·법무 |
| 12편 | 테스트 |

---

## ③ 사용 단계 (StepHow 스텝 캡션)

1. 메인 화면 **왼쪽의 사규 분류 트리**에서 찾고자 하는 주제의 편을 확인합니다. (예: 인사 관련 → `6편 인사·복지`)
2. 해당 편 오른쪽의 **`∨`** 를 클릭하면 그 편에 속한 사규 목록이 펼쳐집니다. `📸 펼쳐진 하위 목록 캡처 필요`
3. 펼쳐진 목록에서 원하는 **사규명을 클릭**합니다.
4. 선택한 사규의 **상세(본문) 화면**으로 이동합니다. (자세한 방법은 *04. 사규 상세 보기* 참고)
5. 다른 편을 보려면 펼쳐진 편의 `∨`(또는 편 이름)을 다시 눌러 접고, 원하는 편을 펼칩니다.
6. 화면을 넓게 보려면 트리 상단의 **`<`** 버튼으로 좌측 사이드바를 접을 수 있습니다. `📸 동작 확인 필요`

---

## ④ 참고 / 팁

- 사규명을 정확히 안다면 분류 탐색 대신 **중앙 검색창**을 쓰는 것이 더 빠릅니다. (*03. 사규 검색하기* 참고)
- `12편 테스트` 는 테스트용 분류로 보이며, 실제 사용 시에는 노출되지 않을 수 있습니다. `📸 오픈본 기준 확인 필요`

---

> 📸 **캡처 가이드**: ① 좌측 트리 전체 → ② 한 편을 펼친 상태(하위 사규 노출) → ③ 사규명에 마우스를 올린 상태 순으로 캡처하면 좋습니다.
