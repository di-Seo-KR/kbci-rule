# KB신용정보 사규관리시스템 사용자 매뉴얼 (초안)

> 본 문서는 **사규관리시스템 사용자용 매뉴얼**을 StepHow로 제작하기 위한 **콘텐츠 초안**입니다.
> 각 화면(가이드)별로 **① 화면 개요 → ② 화면 구성 → ③ 사용 단계(StepHow 스텝 캡션)** 순서로 작성되어 있습니다.
> 초안 작성 시점에 확보된 화면은 메인 화면 1종이며, 나머지 화면은 표준 구성을 기준으로 한 초안입니다. (`📸 캡처 확인 필요` 표기 부분은 실제 화면 확인 후 보완 필요)

## 2. 목차 (StepHow 가이드 단위)

화면(기능) 단위로 가이드를 나눕니다. 한 가이드 = 한 화면/한 작업 흐름을 권장합니다.

| No | 가이드(화면) | 핵심 내용 | 상태 |
|----|------------|----------|------|
| 01 | 메인 화면 둘러보기 | 전체 레이아웃·메뉴 안내 | ✅ 캡처 확보 |
| 02 | 사규 분류로 찾기 (좌측 트리) | 1편~12편 분류 탐색 | 🟡 초안 / 📸 일부 캡처 필요 |
| 03 | 사규 검색하기 | 통합 검색창 사용·결과 보기 | 🟡 초안 / 📸 결과화면 캡처 필요 |
| 04 | 사규 상세(본문) 보기 | 본문·개정이력·별표/부록 열람 | 🟡 초안 / 📸 캡처 필요 |
| 05 | 사규 캘린더 보기 | 시행일자 기준 일정 확인 | 🟡 초안 / 📸 캡처 필요 |
| 06 | 공지사항·별표/부록 확인 | 우측 패널·상세 보기 | 🟡 초안 / 📸 상세화면 캡처 필요 |
| 07 | 법령 검색 (외부 연계) | 국가법령정보 등 외부 링크 | 🟡 초안 / 📸 연결대상 확인 필요 |
| 08 | 본인 인증 / 로그인 | 우측 상단 본인 인증 | 🟡 초안 / 📸 인증화면 캡처 필요 |

> 상태 범례: ✅ 확정(캡처 확보) · 🟡 초안(검토/캡처 필요) · 📸 실제 화면 캡처 후 보완

## 3. 작성 규칙 (StepHow 캡션 스타일)

- **존댓말 + 동작 중심**의 간결한 문장으로 작성합니다. (예: "검색창에 키워드를 입력합니다.")
- **버튼·메뉴·탭 이름**은 대괄호로 표기합니다. (예: `[사규 검색]`, `[더보기]`)
- **한 스텝 = 한 동작**을 원칙으로 합니다.
- 화면 캡처가 필요한 부분은 `📸` 로 표시합니다.
- 화면에 보이는 실제 명칭(라벨)을 그대로 사용합니다.

---

## 4. 용어 정리

| 용어 | 설명 |
|------|------|
| 사규 | 회사 내부 규정(정관·규정·지침 등)을 통칭 |
| 제정 | 새로운 사규를 새로 만드는 것 |
| 개정 | 기존 사규의 내용을 고치는 것 |
| 폐지 | 기존 사규를 없애는 것 |
| 시행일자 | 해당 사규(제·개정 등)가 실제로 효력을 갖는 날짜 |
| 편(編) | 사규를 주제별로 묶은 최상위 분류 (예: 6편 인사·복지) |
| 별표·부록 | 사규 본문에 딸린 표·서식·부속 문서 |
| 본인 인증 | 사용자 확인(로그인) 절차 |
