# 06. 공지사항 · 별표/부록 확인

## ① 화면 개요

메인 화면 **오른쪽 패널**에서 시스템 안내(공지)와 사규에 딸린 자료(별표·부록)를 확인할 수 있습니다.
`[공지사항]` 과 `[별표·부록]` 두 개의 탭으로 구성되어 있습니다.

---

## ② 화면 구성

| 영역 | 설명 |
|------|------|
| `[공지사항]` 탭 | 시스템 점검·오픈 등 안내. `번호` · `제목` · `등록일자` 표시 |
| `[별표·부록]` 탭 | 사규에 딸린 표·서식 등 부속 문서 목록 |
| 목록 항목 | 제목 클릭 시 상세 내용 표시 `📸 상세 화면 캡처 필요` |
| `[더 보기]` | 목록 하단 — 전체 목록 보기 |

---

## ③ 사용 단계 (StepHow 스텝 캡션)

### 공지사항 확인
1. 메인 화면 **오른쪽의 `[공지사항]`** 탭을 확인합니다. (기본 선택 상태)
2. 목록에서 확인할 **공지 제목을 클릭**합니다. (예: `버전 업데이트에 따른 서비스 일시 중지 안내`)
3. 공지 상세 내용을 확인합니다. `📸 상세 화면 캡처 필요`
4. 더 많은 공지를 보려면 목록 하단 **`[더 보기]`** 를 클릭합니다.

### 별표·부록 확인
5. 오른쪽 패널 상단의 **`[별표·부록]`** 탭을 클릭합니다.
6. 목록에서 필요한 **별표·부록 제목을 클릭**해 내용을 확인하거나 다운로드합니다. `📸 동작 확인 필요`
7. 더 많은 자료를 보려면 **`[더 보기]`** 를 클릭합니다.

---

> 📸 **확인 필요 항목**
> - 공지/별표·부록 상세 화면 구성
> - 별표·부록의 파일 다운로드 지원 여부 및 형식
> - 첨부파일/인쇄 기능 유무
