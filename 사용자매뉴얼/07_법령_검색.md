# 07. 법령 검색 (외부 연계)

> ⚠️ 연결 대상 사이트가 확인되지 않아 초안입니다. 실제 연결 주소(예: 국가법령정보센터 등) 확인 후 보완이 필요합니다. `📸`

## ① 화면 개요

상단 메뉴 **`[법령 검색]`** 은 사규의 근거가 되는 **법령을 외부 사이트에서 검색**할 수 있도록 연결해 주는 메뉴입니다.
메뉴 옆 `↗` 표시처럼 **새 창(외부 사이트)** 으로 열립니다.

---

## ② 화면 구성

| 영역 | 설명 |
|------|------|
| `[법령 검색]` 메뉴 | 상단 메뉴 우측, 외부 링크(`↗`) 아이콘 포함 |
| 외부 법령 사이트 | 새 창에서 열리는 법령 검색 페이지 `📸 연결 대상 확인 필요` |

---

## ③ 사용 단계 (StepHow 스텝 캡션)

1. 상단 메뉴에서 **`[법령 검색]`** 을 클릭합니다.
2. **새 창(또는 새 탭)** 으로 외부 법령 검색 사이트가 열립니다. `📸 연결 대상 캡처 필요`
3. 해당 사이트의 검색창에 찾고자 하는 **법령명/키워드**를 입력해 검색합니다.
4. 사규관리시스템으로 돌아오려면 **기존 탭/창**으로 전환합니다.

---

> 📸 **확인 필요 항목**
> - 실제 연결되는 외부 사이트(주소)
> - 새 창 / 새 탭 / 동일 창 중 열리는 방식
> - 별도 로그인 필요 여부
