# 03. 사규 검색하기

## ① 화면 개요

화면 **중앙 상단의 통합 검색창**을 이용하면 사규명이나 키워드로 원하는 사규를 빠르게 찾을 수 있습니다.

---

## ② 화면 구성

| 영역 | 설명 |
|------|------|
| 통합 검색창 | "검색어를 입력하세요" 안내 문구가 있는 입력창 |
| 검색 버튼 (🔍) | 검색창 오른쪽 돋보기 아이콘 — 클릭 시 검색 실행 |
| 검색 결과 목록 | 입력한 키워드와 일치하는 사규 목록 `📸 결과 화면 캡처 필요` |

---

## ③ 사용 단계 (StepHow 스텝 캡션)

1. 메인 화면 **중앙의 검색창**을 클릭합니다.
2. 찾고자 하는 **사규명 또는 키워드**를 입력합니다. (예: `정보보호`, `복무규정`)
3. 키보드 **`Enter`** 를 누르거나 검색창 오른쪽의 **돋보기(🔍) 버튼**을 클릭합니다.
4. 입력한 키워드와 관련된 **사규 목록**이 표시됩니다. `📸 검색 결과 화면 캡처 필요`
5. 결과 목록에서 원하는 **사규명을 클릭**하면 상세(본문) 화면으로 이동합니다. (자세한 방법은 *04. 사규 상세 보기* 참고)
6. 원하는 결과가 없으면 검색어를 바꾸거나 줄여서 다시 검색합니다.

---

## ④ 참고 / 팁

- 너무 긴 문장보다 **핵심 단어**로 검색하면 더 정확합니다. (예: "임직원 복무에 관한 규정" → `복무`)
- 검색 결과가 많으면, 좌측 **분류 트리**(편)와 함께 활용해 범위를 좁힐 수 있습니다.

---

> 📸 **확인/캡처 필요 항목**
> - 검색 결과 화면의 구성(정렬 기준, 표시 항목, 결과 건수 표기 등)
> - 검색 시 자동완성/추천어 기능 유무
> - 본문 내용 검색 지원 여부 (사규명만 검색 vs. 본문 포함 검색)
