# 08. 본인 인증 / 로그인

> ⚠️ 인증 화면 캡처가 확보되지 않아 표준 구성을 기준으로 작성한 초안입니다. 실제 인증 방식 확인 후 보완이 필요합니다. `📸`

## ① 화면 개요

화면 **우측 상단의 `[본인 인증]`** 은 사용자를 확인하는 절차입니다.
사규 열람 권한 확인 등 본인 인증이 필요한 경우 사용합니다.

---

## ② 화면 구성 (예상) `📸 캡처 확인 필요`

| 영역 | 설명 |
|------|------|
| `[본인 인증]` 버튼 | 우측 상단. 클릭 시 인증 절차 시작 |
| 인증 수단 | 사번/사내 계정, 휴대폰 인증, 통합 로그인(SSO) 등 `📸 방식 확인 필요` |
| 인증 완료 표시 | 인증 후 사용자명/상태 표시 |

---

## ③ 사용 단계 (StepHow 스텝 캡션) `📸 캡처 확인 필요`

1. 화면 **우측 상단의 `[본인 인증]`** 을 클릭합니다.
2. 안내에 따라 **인증 수단**을 선택하고 정보를 입력합니다. `📸 실제 인증 방식 확인 필요`
3. 인증이 완료되면 우측 상단에 **인증 상태(사용자 정보)** 가 표시됩니다.
4. 이후 인증이 필요한 사규 열람·기능을 정상적으로 이용할 수 있습니다.

---

> 📸 **확인 필요 항목**
> - 실제 인증 방식 (사내 SSO / 휴대폰 본인인증 / 사번·비밀번호 등)
> - 인증 없이 열람 가능한 범위 vs. 인증 필요한 범위
> - 로그아웃 / 인증 해제 방법
> - 인증 유지 시간(자동 로그아웃) 안내
