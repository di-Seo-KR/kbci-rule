# 05. 사규 캘린더 보기

> ⚠️ 본 화면은 캡처가 확보되지 않아 표준 구성을 기준으로 작성한 초안입니다. 실제 화면 확인 후 보완이 필요합니다. `📸`

## ① 화면 개요

상단 메뉴 **`[사규 캘린더]`** 에서 진입하는 화면으로, 사규의 **시행일자(제·개정·폐지 일정)** 를 달력 형태로 한눈에 확인할 수 있습니다.

---

## ② 화면 구성 (예상) `📸 캡처 확인 필요`

| 영역 | 설명 |
|------|------|
| 월(月) 달력 | 날짜별 사규 일정 표시 |
| 이전/다음 달 이동 | `<` `>` 버튼으로 월 이동 |
| 일정 항목 | 해당일 시행 사규명·구분(제정/개정/폐지) |
| 상세 보기 | 일정 클릭 시 해당 사규 상세로 이동 |

---

## ③ 사용 단계 (StepHow 스텝 캡션) `📸 캡처 확인 필요`

1. 상단 메뉴에서 **`[사규 캘린더]`** 를 클릭합니다.
2. 달력 형태로 **사규 시행 일정**이 표시됩니다.
3. **`<` / `>`** 버튼으로 보고 싶은 달(月)로 이동합니다.
4. 날짜 칸에 표시된 **사규 일정**에서 시행되는 사규와 구분(제정/개정/폐지)을 확인합니다.
5. 특정 일정을 **클릭**하면 해당 사규의 상세(본문) 화면으로 이동합니다. `📸 동작 확인 필요`

---

> 📸 **확인 필요 항목**
> - 캘린더 표시 단위(월/주/리스트) 및 기본 보기
> - 일정에 표시되는 정보(사규명, 구분, 색상 구분 등)
> - 일정 클릭 시 동작(상세 이동/팝업 등)
> - 기간/구분 필터 기능 유무
