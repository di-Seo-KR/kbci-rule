# 메인(홈) 화면

접속 시 처음 보이는 화면으로, **좌측 분류 메뉴**와 **중앙 목록 영역**으로 구성됩니다.

## 좌측 메뉴 트리
사규를 **편(編) → 사규 → 별표·서식** 3단계로 분류합니다.
- 편(예: `8편 IT·정보보호`) 클릭 → 소속 사규 펼침
- 사규명 클릭 → 본문(상세) 이동
- `[+]` 표시 사규 클릭 → 딸린 별표·서식 펼침

## 중앙 목록 영역
검색창 아래 두 목록이 탭으로 제공되며, 각 하단 `[더 보기]`로 전체를 볼 수 있습니다.
- **사규 개정 / 제정·폐지** : 최근 변경된 사규 (`구분 · 사규명 · 시행일자`)
- **공지사항 / 별표·부록** : 시스템 공지·부속 자료 (`번호 · 제목 · 등록일자`)

※ 사규명·제목 클릭 시 상세 화면으로 이동합니다.
