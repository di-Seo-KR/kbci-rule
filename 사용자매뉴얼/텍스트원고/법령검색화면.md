# 법령 검색 화면 (외부 연계)

`[법령 검색]` 클릭 시 외부 법령 검색 시스템 **위로(WiLaw)** 가 새 창으로 열립니다.

- **검색** : `법령명 ▼`(검색 유형)을 선택하고 키워드 입력 후 `[검색]`. 좌측에 결과 목록(시행일·개정 정보 포함)이 표시됩니다.
- **본문** : 법령을 선택하면 조문 전문이 표시되며, 본문·부칙·별표를 펼쳐 볼 수 있습니다.
- **저장** : 본문을 `HTML / PDF / DOCX`로 저장합니다. `범위설정`(일부/선택 저장 · 조문 선택 · 포함 옵션)과 `용지·폰트 설정`을 지정할 수 있습니다.
