# 사규 본문 조회 화면

사규명을 클릭하면 열리는 본문 열람 화면으로, **좌측 분류 · 중앙 목차 · 우측 본문**으로 구성됩니다.

- **사규 정보** : 사규명과 함께 담당부서(예: `경영전략부`) · `시행일자` · `별표/부록` 건수 등을 표시
- **목차** : 조문(제1조~) · 부칙 · 별표/부록 목록. 항목 클릭 시 본문의 해당 위치로 이동하며, `[모두 접기]`로 접을 수 있음
- **본문** : 선택한 사규의 조문 전문을 표시
- **별표/부록** : 목차 또는 상단 정보의 `별표/부록`에서 부속 자료 확인
