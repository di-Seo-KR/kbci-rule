# 사규 본문 조회 화면

사규명을 클릭하면 열리는 본문 열람 화면으로, **좌측 분류 · 중앙 목차 · 우측 본문**으로 구성됩니다.

- **사규 정보** : 사규명과 담당부서(예: `경영전략부`) · `시행일자` · `별표/부록` 건수를 표시 (`[상세보기]`로 추가 정보 확인)
- **목차** : 장(章) → 절(節) → 조(條) 구조로 펼침/접힘(▼), 항목 클릭 시 본문의 해당 위치로 이동 (`[모두 접기]` 지원)
- **본문** : 선택한 사규의 조문 전문을 표시

## 본문 기능 버튼 (우측 상단)
- **개정이력** : 과거 개정 이력·버전 조회
- **본문 검색** : 본문 내 검색 후 `[이전]`·`[다음]`으로 이동
- **가- / 원래대로 / 가+** : 글자 크기 조절
- **2단보기** : 본문을 2단으로 보기
- **신구대비** : 신·구 조문 대비
- **전문다운** : 전문(전체 본문) 다운로드
- **안내** : 사용 안내
