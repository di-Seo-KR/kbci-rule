# 04. 사규 상세(본문) 보기

> ⚠️ 본 화면은 캡처가 확보되지 않아 표준 구성을 기준으로 작성한 초안입니다. 실제 화면 확인 후 보완이 필요합니다. `📸`

## ① 화면 개요

검색 결과 또는 분류 트리에서 사규명을 클릭하면 이동하는 **사규 본문 열람 화면**입니다.
사규의 전체 조문과 시행일자, 개정 이력, 별표·부록 등을 확인할 수 있습니다.

---

## ② 화면 구성 (예상) `📸 캡처 확인 필요`

| 영역 | 설명 |
|------|------|
| 사규명/구분 | 사규 제목과 `제정/개정/폐지` 구분 |
| 시행일자 | 현재 열람 중인 버전의 시행일자 |
| 본문(조문) | 장·절·조 단위 사규 전문 |
| 개정 이력 | 이전 버전·연혁 보기 (이전/현행 비교 등) |
| 별표·부록 | 본문에 딸린 표·서식 다운로드/열람 |
| 인쇄/다운로드 | PDF 등 출력·저장 기능 |

---

## ③ 사용 단계 (StepHow 스텝 캡션) `📸 캡처 확인 필요`

1. 검색 결과 또는 분류 트리에서 원하는 **사규명을 클릭**합니다.
2. 선택한 사규의 **본문(조문)** 이 화면에 표시됩니다.
3. 화면 상단에서 해당 사규의 **`시행일자`** 와 구분(`개정` 등)을 확인합니다.
4. 본문을 스크롤하여 필요한 조문을 확인합니다.
5. 과거 내용을 보려면 **`개정 이력`**(연혁)에서 이전 버전을 선택합니다. `📸 명칭·위치 확인 필요`
6. 사규에 딸린 표·서식이 필요하면 **`별표·부록`** 에서 해당 항목을 열람·다운로드합니다. `📸 확인 필요`
7. 출력이 필요하면 **`인쇄`/`다운로드`** 기능을 이용합니다. `📸 지원 여부·명칭 확인 필요`

---

> 📸 **확인 필요 항목**
> - 상세 화면 실제 레이아웃 및 버튼 명칭
> - 개정 이력/버전 비교 기능 유무 및 명칭
> - 인쇄·PDF 다운로드 지원 여부
> - 본인 인증이 필요한 사규(열람 권한) 여부
