# 01. 메인 화면 둘러보기

## ① 화면 개요

사규관리시스템에 접속하면 가장 먼저 표시되는 **메인(홈) 화면**입니다.
자주 쓰는 기능을 한눈에 볼 수 있도록 **상단 메뉴 · 좌측 사규 분류 · 중앙 검색/최근 사규 · 우측 공지/별표·부록** 영역으로 구성되어 있습니다.

---

## ② 화면 구성

| 영역 | 위치 | 설명 |
|------|------|------|
| 로고 | 좌측 상단 | `[KB 신용정보 사규관리시스템]` — 클릭하면 언제든 메인 화면으로 이동 |
| 상단 메뉴(GNB) | 상단 중앙 | `[사규 검색]` · `[사규 캘린더]` · `[법령 검색]` (법령 검색은 외부 링크 ↗) |
| 본인 인증 | 우측 상단 | `[본인 인증]` 버튼 — 사용자 인증/로그인 |
| 사규 분류 트리 | 좌측 | `1편 정관·이사회` ~ `12편 테스트` 분류. `∨` 클릭으로 펼쳐서 하위 사규 탐색 |
| 통합 검색창 | 중앙 상단 | "검색어를 입력하세요" — 사규명·키워드 검색 |
| 사규 개정 / 사규 제정·폐지 | 중앙 | 최근 시행 사규 목록 (`구분` · `사규명` · `시행일자`) |
| 공지사항 / 별표·부록 | 우측 | 공지·별표/부록 목록 (`번호` · `제목` · `등록일자`) |
| 더보기 | 각 목록 하단 | `[더 보기]` — 해당 목록 전체 보기 |

---

## ③ 사용 단계 (StepHow 스텝 캡션)

1. 브라우저 주소창에 **`kbregulation.wizice.com`** 을 입력하여 사규관리시스템에 접속합니다.
2. 메인 화면이 표시됩니다. 화면은 크게 **상단 메뉴 · 좌측 분류 · 중앙 검색/목록 · 우측 공지** 4개 영역으로 나뉩니다.
3. 상단 메뉴에서 `[사규 검색]` `[사규 캘린더]` `[법령 검색]` 중 원하는 기능을 선택해 이동합니다.
   - `[법령 검색]` 은 외부 사이트(↗)로 새 창에서 열립니다.
4. 화면 중앙의 검색창에 찾고자 하는 **사규명이나 키워드**를 입력하면 사규를 빠르게 검색할 수 있습니다. (자세한 방법은 *03. 사규 검색하기* 참고)
5. 화면 왼쪽의 **사규 분류 트리**에서 `∨` 를 눌러 편을 펼치고, 원하는 분류의 사규를 찾습니다. (자세한 방법은 *02. 사규 분류로 찾기* 참고)
6. 중앙의 **`[사규 개정]`** 탭에서 최근에 개정되어 시행된 사규를 `시행일자` 순으로 확인합니다.
7. **`[사규 제정·폐지]`** 탭을 누르면 새로 제정되거나 폐지된 사규 목록으로 전환됩니다.
8. 목록의 **사규명을 클릭**하면 해당 사규의 상세(본문) 화면으로 이동합니다. (자세한 방법은 *04. 사규 상세 보기* 참고)
9. 화면 오른쪽 **`[공지사항]`** 에서 시스템 점검·오픈 등 안내를 확인합니다.
10. 오른쪽 **`[별표·부록]`** 탭을 누르면 사규에 딸린 표·서식 등 별표·부록 목록을 볼 수 있습니다.
11. 각 목록을 더 보려면 목록 하단의 **`[더 보기]`** 를 클릭합니다.
12. 사규 열람·인증이 필요한 경우 우측 상단의 **`[본인 인증]`** 을 클릭해 사용자 인증을 진행합니다. (자세한 방법은 *08. 본인 인증* 참고)

---

## ④ 참고 / 팁

- 로고(`[KB 신용정보 사규관리시스템]`)를 클릭하면 어느 화면에서든 메인으로 돌아올 수 있습니다.
- `사규 개정` / `사규 제정·폐지` 목록의 **`구분` 배지**(예: `개정`)로 변경 유형을 빠르게 구분할 수 있습니다.
- 좌측 분류 트리의 `<` 버튼으로 사이드바를 접어 화면을 넓게 쓸 수 있습니다. `📸 동작 확인 필요`

---

> 📸 **캡처 가이드**: 메인 화면 전체 1컷 → 상단 메뉴 영역 → 좌측 분류 영역 → 중앙 검색/목록 영역 → 우측 공지/별표 영역 순으로 캡처하면 스텝 흐름과 맞습니다.
