[별표 5] 비밀번호 작성규칙

 






비밀번호 작성규칙

정보시스템 사용자(통합전산 사용자 및 콘솔 등을 이용하여 서버에 접근하는 자)와 
업무용PC 사용자(당사 자산관리규정 제1조에 의한 업무용 동산에 해당하는 PC를 사용자는자)의 경우 이 비밀번호 작성규칙을 따른다.
비밀번호는 외부의 노출을 막고, 타인이 추측하지 못하도록 다음과 같은 규칙을 적용한다.

1. 비밀번호 구성 및 길이(시스템 제약 사항)
-    비밀번호는 숫자만으로 구성할 수 없음
-    문자(영어 대소문자), 숫자(0~9, 10개), 특수문자를 조합하여 구성
-    문자/숫자/특수문자 중 3종류 이상을 조합하여 최소 8자리 이상의 길이로 설정
-    문자/숫자/특수문자 중 2종류 이상을 조합하여 최소 10자리 이상의 길이로 설정

2. 생성 유의 사항(시스템 제약 사항)
-    변경 시 기존 사용하던 동일한 비밀번호 사용 금지
-    비밀번호에 같은 문자를 4번 이상 사용 금지
-    사용자계정(ID)이 포함된 비밀번호 사용 금지
-    주민번호가 포함된 비밀번호 사용 금지

3. 비밀번호 변경 주기
-    최소 3개월마다 변경할 것
-    3개월 내에 미 변경 시에는 시스템에서 접속 차단

4. 기타 유의사항
-    동일 비밀번호를 여러 사람이 공유하여 사용 금지 
-    예측이 가능한 구성 사용 금지
예) 영문이름약자, 전화번호, 일련번호, 생일, 잘 알려진 단어, 키보드 상의 연속문자열 등
-    비밀번호 만료 시에는 부/지점장 권한으로 SMS로 초기화된 비밀번호가 전송됨
-    초기화 비밀번호는 문자, 숫자 혼합으로 10자리 조합으로 구성
