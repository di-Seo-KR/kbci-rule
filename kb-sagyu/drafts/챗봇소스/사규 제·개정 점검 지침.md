# 사규 제·개정 점검 지침

> **이 문서의 용도**
> KB신용정보 임직원이 사규 제·개정 전문(全文)을 올리면, 그 문서가 「사규관리규정」의 작성 기준에 맞는지 점검하고 정정안을 제시하기 위한 지침이다.
> 함께 올린 **「사규관리규정」 원문이 유일한 규범 근거**이고, 이 문서는 그 규정을 실제 사규에 적용할 때 반복해서 나온 오류 유형과 점검 절차를 정리한 실무 안내서다.
> 두 자료가 어긋나면 **언제나 「사규관리규정」 원문이 우선**한다.

기준 규정: 「사규관리규정」(2026. 8. 12. 개정-2026-024, 23조)
작성: 경영전략부

---

## 0. 답변 방식 — 이 순서와 형식을 지킬 것

### 0.1 반드시 지킬 것

1. **근거 조문 없이 지적하지 않는다.** 모든 지적에는 `「사규관리규정」 제○조제○항제○호`를 붙인다. 근거를 못 찾으면 "규정에 명시 없음 — 관행상 권고"라고 밝히고 지적과 구분한다.
2. **실체 조문은 손대지 않는다.** 지급 금액·요율·기간·요건·절차 같은 내용은 점검 대상이 아니다. 이 지침의 점검 범위는 **표기·형식**과 **사규관리규정이 요구하는 구성**까지다. 내용상 문제가 눈에 띄면 "참고 사항"으로 따로 적고, 정정안에는 반영하지 않는다.
3. **모르는 것은 지어내지 않는다.** 날짜·문서번호·부서명·서식 명칭을 알 수 없으면 `○○○○. ○. ○.` 같은 자리표시로 두고 "확인 요망"으로 표시한다. 특히 **부칙의 제정일과 별표 개정일자는 문서에 없으면 절대 추측하지 않는다.**
4. **인용한 다른 사규의 조문이 실재하는지 확인할 수 없으면** "인용 조문 실재 여부 확인 필요"로 표시한다.
5. **색상은 문서에서 직접 확인할 수 없을 수 있다.** 업로드된 문서에서 글자색을 판별할 수 없으면 "색상은 원본에서 직접 확인 필요"라고 안내하고, 색상 기준(제16조)을 함께 알려준다.

## 1. 점검 절차

문서를 받으면 아래 순서로 훑는다. 앞 단계에서 걸린 것이 뒤 단계의 판단을 바꾸므로 순서를 지킨다.

| 단계 | 확인할 것 | 근거 |
|---|---|---|
| ① 개정 종류 판정 | 제정 / 일부개정 / **전부개정** / 폐지 중 무엇인가 | 제2조제4호 |
| ② 머리 표기 | 사규명 다음 줄의 `[시행일자] [문서번호]` | 제16조제1항 |
| ③ 본칙 구성 | 총칙 → 실체 → 보칙 순서, 총칙의 구성 | 제9조 |
| ④ 장·절·관 | 표기와 일련번호 | 제13조 |
| ⑤ 조·항·호·목 | 조 표기 붙여쓰기, 항·호·목 기호와 줄바꿈 | 제14조·제15조 |
| ⑥ 개정 표기 | `(일자 개정/신설/삭제)` 형식·위치·색상 | 제16조제2항 |
| ⑦ 인용 부호 | 사규 「」 / 법령 『』 | 제12조제6항 |
| ⑧ 별표·서식 | `[별표 제N호]` `[서식 제N호]` 표기, 부칙 다음 배열, 개정일자 | 제11조·제16조제4항 |
| ⑨ 부칙 | `부 칙(일자 개정사항)`, 조 방식, 시행일 필수 | 제17조·제10조 |
| ⑩ 입안 서류 | 개정 종류별로 신구조문대비표가 필요한지 | 제18조제2항 |

### 개정 종류를 먼저 판정해야 하는 이유

- **전부개정**(개정 조문이 기존 조문의 **2/3 이상**, 제2조제4호)이면
  - 조문마다 `(일자 개정)` 표기를 **하지 않는다** (제16조제3항)
  - 종전 부칙을 **모두 삭제**한다 (제17조제4항, 제21조제3항). 다만 사규소관부서장이 필요하다고 인정하면 일부는 남길 수 있다
  - **신구조문대비표를 생략할 수 있다** (제18조제2항제4호)
- **제정·폐지**도 조문별 개정 표기를 하지 않는다 (제16조제3항)
- **일부개정**이면 위 셋이 모두 반대가 된다

→ 전부개정인데 조문마다 `(개정)` 표기가 붙어 있거나, 일부개정인데 표기가 하나도 없으면 그 자체가 위반이다.

## 2. 오류 유형 카탈로그

아래는 실제 사규(복무규정, 복무규정 시행지침, 신용정보관리 지침, 신용정보업무 규정)를 점검하면서 **반복해서 나온** 유형이다. 새 문서에서도 대부분 이 안에서 나온다.

### 2.1 머리 표기 — 제16조제1항

사규명 바로 다음 줄에 `[시행일자] [최근 제정 및 개폐일자 문서번호]`를 **파란색(R0, G0, B205 = #0000CD)** 으로 쓴다.

| 잘못된 예 | 바른 예 | 문제 |
|---|---|---|
| `[시행 2026. 08. 31.][2026. 08. 31. 개정-2026-026]` | `[시행 2026. 8. 31.] [2026. 8. 31. 개정-2026-026]` | 대괄호 사이 공백 없음 / 월·일 앞 0 |
| 하늘색(#0070C0)으로 표기 | 파란색(#0000CD) | 규정이 정한 색이 아님 |

- **월·일에 0을 채우지 않는다.** 규정 본문의 예시가 `2026. 8. 12.` 형식이다. `08. 31.`이 아니라 `8. 31.`
- **문서번호는 사규관리시스템 채번값**이다(제16조제1항 후단). 모르면 `개정-2026-0○○`로 두고 확인 요망.

### 2.2 조 표기 — 제14조제2항

> "조의 표기는 '제1조, 제2조 ···'으로 하고, **조 바로 다음에 괄호를 만들어** 제목을 작성한다."

| 잘못된 예 | 바른 예 |
|---|---|
| `제1조 (적용)` | `제1조(적용)` |
| `제 13 조의 2(육아기 근로시간 단축)` | `제13조의2(육아기 근로시간 단축)` |
| `제19조2(상거래관계 종료된 …)` | `제19조의2(상거래관계 종료된 …)` |

- 조와 괄호 사이에 **공백을 두지 않는다.** 오래된 사규는 거의 전부 공백이 있으므로 전건을 훑어야 한다.
- 가지번호는 `제○조의○` 형식이다. `제19조2`처럼 '의'가 빠졌거나 `제 13 조의 2`처럼 공백이 낀 것을 고친다.

### 2.3 항·호·목 — 제14조제4항, 제15조제2항·제4항

- 항: `①, ②, ③ ···` — **제2항부터 줄을 바꾼다.** 즉 **제1항은 조 제목과 같은 줄**에 온다.
- 호: `1, 2, 3 ···` — 조 또는 항과 줄을 바꾼다.
- 목: `가, 나, 다 ···` — 호와 줄을 바꾼다.

자주 나오는 오류:

| 유형 | 설명 |
|---|---|
| 조 제목만 한 줄, ①이 다음 줄 | 제14조제4항 위반. 조 제목과 제1항을 한 단락으로 합친다 |
| 한 문장이 두 단락으로 쪼개짐 | 조판 사고. "…목적으" / "로 한다." 처럼 끊긴 것을 합친다 |
| 항 본문과 "다만…" 단서가 다른 단락 | 하나의 항은 하나의 단락으로 |
| 목 아래에 `(1) (2) (3)` 사용 | 제15조는 **목까지만** 정한다. 그 아래 단계는 규정에 없으므로 지적하되, 실무상 필요하면 "규정 정비 필요"로 안내 |

### 2.4 개정 표기 — 제16조제2항 ★ 가장 많이 틀리는 곳

변경된 문구가 속한 **조·항·목 문장 끝**에 붙이고 **파란색(#0000CD)** 으로 쓴다.

| 구분 | 바른 표기 | 근거 |
|---|---|---|
| 개정 | `(2026. 8. 31. 개정)` | 제16조제2항제1호 |
| 신설 | `(2026. 8. 31. 신설)` | 제2호 |
| 삭제 | 문장을 **모두 지우고** `(2026. 8. 31. 삭제)` | 제3호 |

신설 이후 다시 개정되면 `(신설)`이 아니라 `(최근개정일자 개정)`으로 바뀐다(제2호 후단).

**실제로 나온 오류들:**

| 잘못된 예 | 바른 예 | 문제 |
|---|---|---|
| `(2026. 8. 31. 본항 개정)` | `(2026. 8. 31. 개정)` | "본항/본조/본호/본목"은 규정에 없는 표기 |
| `(2025. 04. 21 본항표 개정)` | `(2025. 4. 21. 개정)` | 같음 + 날짜 0채움 + 마침표 누락 |
| `[2025.3.20. 본조 개정]` | `(2025. 3. 20. 개정)` | 대괄호가 아니라 소괄호 |
| `<개정 2025.2.1.>` | `(2025. 2. 1. 개정)` | 꺾쇠 + 일자·사항 순서 뒤바뀜 |
| `2. 삭제 <2025.2.1.>` | `2. (2025. 2. 1. 삭제)` | 같음 |
| `① 삭제 (2025.4.1. 본항 삭제)` | `① (2025. 4. 1. 삭제)` | 제3호는 "문장을 모두 지우고" 표기하라고 함. "삭제"가 두 번 나옴 |
| 표기가 **별도 줄**에 홀로 있음 | 해당 조·항 문장 **끝**에 붙임 | 제16조제2항은 "문장 끝에" |
| 신설 조문 **본문 전체가 빨간색** | 본문은 검정, **표기만 파란색** | 제16조는 표기에만 색을 정함 |
| 빨간색(#FF0000)으로 표기 | 파란색(#0000CD) | 규정이 정한 색이 아님 |

> **색상 정리**
> 파란색(#0000CD)을 쓰는 곳은 **셋뿐**이다 — ① 머리 표기(제16조제1항), ② 조·항·목 개정 표기(제2항), ③ 별표·서식 개정 표기(제4항).
> **부칙은 파란색 대상이 아니다.** 검정으로 쓴다. 본문도 검정이다.

### 2.5 인용 부호 — 제12조제6항

> 다른 사규는 `「사규명」 제00조`, 법령은 `『법률명』 제00조`

| 잘못된 예 | 바른 예 |
|---|---|
| `근로기준법이 정하는 범위` | `『근로기준법』이 정하는 범위` |
| `「근로기준법」 등 관련 법령` | `『근로기준법』 등 관련 법령` |
| `『정관』 제2조` | `「정관」 제2조` (정관은 사규 체계의 최상위, 제5조) |
| `『신용정보관리지침』에서 정한` | `「신용정보관리 지침」에서 정한` |
| `인사규정시행지침에서 정하는` | `「인사규정 시행지침」에서 정하는` |

- **사규와 법령이 서로 반대로 쓰인 경우가 매우 흔하다.** 양방향 모두 확인한다.
- 사규명은 정식 명칭으로 쓴다(띄어쓰기 포함).
- 법령 약칭이 쓰인 경우 부호만 씌우고, 정식 명칭 변경은 실체 변경이므로 "확인 요망"으로 남긴다.

### 2.6 별표·서식 — 제11조, 제16조제4항

**표기**(제11조제3항): `[별표 제1호]`, `[서식 제1호]` — **대괄호**

| 잘못된 예 | 바른 예 |
|---|---|
| `『별표 제1호』` | `[별표 제1호]` |
| `<별표1>`, `<별표 2>` | `[별표 제1호]`, `[별표 제2호]` |
| `『별지 서식 제1호』` | `[서식 제1호]` |
| `<별지서식2> 신용정보 요구서` | `신용정보 요구서[서식 제2호]` |
| `[별지 1]` ~ `[별지 11]` | `[서식 제1호]` ~ `[서식 제11호]` |

**배열**(제11조제1항): 부칙 **다음에** 별표 → 별지 서식 순서로 배열한다. 목록 형태로 제목을 적는다.

**개정 표기**(제16조제4항): 별표·서식 제목 **바로 다음**에 `<변경일자 변경사항>`을 파란색으로.

```
[별표 제1호] 사규 목차 <2026. 6. 23. 개정>
[서식 제1호] 사규 표준 서식 <2026. 6. 23. 개정>
```

- 조·항·목은 **소괄호** `( )`, 별표·서식은 **꺾쇠** `< >`다. 헷갈리지 않는다.
- 개정 이력이 없으면 `< >`를 아예 붙이지 않는다. 제16조제4항은 "개정 시"에만 표기하도록 한다.
- 별표가 실재하는데 **본문에서 한 번도 인용하지 않는 경우**가 있다. 지적 대상이다.
- 표의 행과 열이 **4개 이하**면 별표로 두지 않고 본문 조·항·호·목 끝에 줄을 바꿔 붙일 수 있다(제11조제2항).

### 2.7 부칙 — 제17조, 제10조

**표기**(제17조제2항): `부 칙(제정 및 개폐일자 개정사항)`
규정이 든 예시: `부 칙(2026. 8. 12. 전부개정)`, `(2026. 8. 12. 개정)`

| 잘못된 예 | 바른 예 |
|---|---|
| `부 칙` (일자 없음) | `부 칙(1999. 10. 9. 제정)` |
| `부 칙 (2026. 08. 31.)` | `부 칙(2026. 8. 31. 개정)` |
| `① (시행일) 이 규정은 …` | `제1조(시행일) 이 규정은 …` |
| `② (경과조치) …` | `제2조(경과조치) …` |
| `제1조(시행일자)` | `제1조(시행일)` |
| `이 세칙은 2002. 9. 9 부터` | `이 지침은 2002. 9. 9. 부터` |
| `이 규정은 2009. 4.  1 부터` | `이 규정은 2009. 4. 1. 부터` |

- **부칙은 조로 구분한다**(제17조제1항). 옛 사규는 대부분 `① (시행일)` 항 방식이므로 전건을 조 방식으로 바꾼다.
- 조 제목과 순서는 제10조를 따른다 — 시행일 → 관계 사규의 제정 및 개폐 → 경과조치 및 유효기간 → 그 밖의 부수사항.
- **시행일은 필수**다(제10조제2항). 없으면 위반.
- 본문의 사규 종류가 실제와 맞는지 본다. **지침인데 "이 규정은", "이 세칙은"** 으로 쓴 것이 흔하다(제8조).
- 일자는 `YYYY. M. D.` — 0을 채우지 않고 끝에 마침점을 찍는다.
- **첫 부칙을 "제정"으로 볼지는 문서만으로 알 수 없다.** 임의로 정하지 말고 확인 요망으로 남긴다.
- **전부개정이면 종전 부칙을 모두 삭제한다**(제17조제4항, 제21조제3항).

### 2.8 본칙 구성 — 제9조

> 총칙 → 실체 → 보칙

- **총칙**: 목적, 용어의 정의, 적용 범위, 다른 사규와의 관계
- **실체**: 업무 흐름·중요도·적용빈도 순서로 배열
- **보칙**: 특례, 그 밖의 부수적 사항

자주 나오는 문제:

| 유형 | 설명 |
|---|---|
| **목적 조문이 없다** | 제1조가 `(적용)`으로 시작하는 등. 제9조제1호 위반 |
| **정의 조문이 없는데 용어를 쓴다** | 적용대상에 "직원가족"을 두면서 그 범위를 정하지 않는 식 |
| **보칙 장이 없다** | 위임·재검토기한 등이 갈 곳이 없음 |
| **총칙이 아예 없다** | 제1장이 곧바로 실체 사항으로 시작 |
| 같은 이름의 장이 둘 | 제1장·제2장이 모두 「총칙」인 경우 |

표제는 표준형을 쓴다 — 「정의」(용어의 정의 ✗), 「적용범위」(적용대상 ✗), 「시행일」(시행일자 ✗), 마지막 장은 「보칙」(기타 ✗).

### 2.9 조문 번호 연속성

- 조는 **장·절·관과 무관하게 제1조부터 순차**로 붙인다(제14조제1항).
- 번호가 비거나 중복되면 지적한다. 같은 조번호가 두 번 나오는 사고가 실제로 있었다.
- **조번호를 옮기면 그 조를 인용한 다른 조문과 다른 사규까지 어긋난다.** 재번호가 필요하면 "외부 인용 영향 검토 필요"로 반드시 경고한다.

### 2.10 입안 서류 — 제18조제2항

제·개정안에는 다음이 들어가야 한다.

1. 입안 사유
2. 입안 주요 내용
3. 입안 본문
4. **신구조문 대비표** — 다만 **제정·전부개정·폐지는 생략**

전문만 올라오면 "입안 서류로는 사유·주요 내용·(해당 시)신구조문대비표가 함께 필요하다"고 안내한다.

## 3. 표기 점검 범위 밖이지만 알려줄 가치가 있는 것

아래는 **정정안에 반영하지 않고** "참고" 항목으로만 적는다. 소관부서의 정책 판단이 필요한 사항이다.

| 유형 | 실제로 나온 예 |
|---|---|
| **착지 없는 위임** | "별도로 정하는 바에 따른다", "시행지침에서 정하는 바에 의한다" — 정작 그 시행지침에 해당 조문이 없음 |
| **미정의 용어** | "중요 정보"를 금지 대상으로 삼는데 정의 조문에 없음. 같은 지침이 다른 조에서는 "기밀·대외비"라는 다른 분류를 씀 |
| **폐지된 법령·제도 개념** | 호적등본(2008년 호주제 폐지), 육성회비, 본적지 |
| **검증 불가능한 요건** | 소요시간으로 지급 기준을 나누는데 확인할 방법이 신고뿐인 경우 |
| **근거 없는 대장·서식** | 실무에서 쓰는 대장이 사규에 근거가 없음 |
| **역위계 준용** | 하위 사규가 "관계 법령을 준용한다"고 규정 |
| **조문 간 중복·충돌** | 두 조문의 지급 요건과 금액이 완전히 동일 |
| **조번호 중복** | 같은 조번호가 두 번 나옴 |

## 4. 자주 받는 질문에 대한 답

**Q. 전부개정인지 일부개정인지 어떻게 판단하나요?**
개정되는 조문이 기존 조문의 **2/3 이상**이면 전부개정이다(제2조제4호). 조문 수로 센다.

**Q. 전부개정인데 종전 부칙을 남기고 싶습니다.**
가능하다. 제17조제4항 단서가 "사규소관부서장이 필요하다고 인정하는 경우에는 일부 부칙을 삭제하지 않을 수 있다"고 한다. 다만 남기는 이유를 입안 사유에 적는 것이 좋다.

**Q. 신구조문대비표를 꼭 만들어야 하나요?**
일부개정이면 필요하다. 제정·전부개정·폐지는 생략할 수 있다(제18조제2항제4호). 다만 전부개정도 심사 편의를 위해 첨부하는 경우가 많다.

**Q. 시행일을 안 정하면 어떻게 되나요?**
부칙 시행일은 필수다(제10조제2항). 정하지 않으면 제정·개정이 확정된 날부터 효력이 발생한다(제20조 단서).

**Q. 표를 넣고 싶은데 별표로 해야 하나요?**
행과 열이 각각 4개 이하면 별표로 두지 않고 본문 해당 조·항·호·목 끝에 줄을 바꿔 붙일 수 있다(제11조제2항).

**Q. 문서번호는 어떻게 정하나요?**
사규관리시스템에서 채번한다(제16조제1항 후단). 입안 단계에서는 `개정-2026-0○○`로 비워두고 결재 후 채운다.

**Q. 개정 표기를 언제 지우나요?**
규정에 정한 바가 없다. 실무상 전부개정 때 정리한다. 전부개정·제정·폐지는 조문별 개정 표기를 하지 않으므로(제16조제3항) 자연히 사라진다.

## 5. 빠른 점검표

문서를 올리기 전에 스스로 훑어볼 목록이다.

- [ ] 사규명 다음 줄에 `[시행 YYYY. M. D.] [YYYY. M. D. 개정-YYYY-NNN]`이 파란색으로 있는가
- [ ] 대괄호 사이에 공백이 있는가 / 월·일에 불필요한 0이 없는가
- [ ] 모든 조가 `제N조(제목)` 붙여쓰기인가
- [ ] 제1항이 조 제목과 같은 줄에 있는가
- [ ] 개정 표기가 `(YYYY. M. D. 개정|신설|삭제)` 형식이고 파란색이며 문장 끝에 붙어 있는가
- [ ] "본항/본조/본호/본목"이 남아 있지 않은가
- [ ] 신설 조문 본문이 검정인가 (표기만 파란색)
- [ ] 다른 사규는 「」, 법령은 『』인가
- [ ] 별표·서식이 `[별표 제N호]` `[서식 제N호]`인가
- [ ] 별표·서식 목록이 부칙 다음에 배열되어 있는가
- [ ] 부칙이 `부 칙(YYYY. M. D. 개정)` 형식이고 조 방식(`제1조(시행일)`)인가
- [ ] 부칙 본문의 사규 종류가 맞는가 ("이 규정은" / "이 지침은")
- [ ] 총칙에 목적·정의·적용범위·다른 사규와의 관계가 있는가
- [ ] 마지막 장이 「보칙」인가
- [ ] 조번호가 제1조부터 빠짐없이 이어지는가
- [ ] 전부개정이면 조문별 개정 표기를 빼고 종전 부칙을 삭제했는가
- [ ] 일부개정이면 신구조문대비표를 첨부했는가

## 6. 정정 예시 — 실제 사례

### 6.1 부칙 (복무규정)

**정정 전**
```
부 칙

① (시행일) 이 규정은 1999. 10. 9 부터 시행한다.

부 칙

① (시행일) 이 규정은 2005. 2. 25부터 시행한다.
② (경과조치) 제19조 제1항 및 제21조 2호는 2005년 12월 31일부터 시행한다.

부 칙 (2026. 08. 31.)

① (시행일) 이 규정은 2026. 08. 31. 부터 시행한다.
```

**정정 후**
```
부 칙(1999. 10. 9. 제정)          ← 제정 여부 확인 요망

제1조(시행일) 이 규정은 1999. 10. 9. 부터 시행한다.

부 칙(2005. 2. 25. 개정)

제1조(시행일) 이 규정은 2005. 2. 25. 부터 시행한다.
제2조(경과조치) 제19조제1항 및 제21조제2호는 2005년 12월 31일부터 시행한다.

부 칙(2026. 8. 31. 개정)

제1조(시행일) 이 규정은 2026. 8. 31. 부터 시행한다.
```

근거: 제17조제1항(조 구분)·제2항(표기)·제3항(조 제목), 제10조제1항

### 6.2 개정 표기 (복무규정 제22조)

**정정 전** — 신설 항 전체가 빨간색, 표기가 별도 줄
```
② 회사는 18세 이상의 여성을 … 동의를 받아야 한다. (2026. 8. 31. 본항 신설)
③ 회사는 임산부와 18세 미만자를 … 근로 시키지 못한다.
다만, 다음 각 호의 어느 하나에 해당하는 경우로서 … 그러하지 아니하다.
1. 18세 미만자의 동의가 있는 경우
(2026. 8. 31. 본항 신설)
```

**정정 후** — 본문 검정, 표기만 파란색, 문장 끝에 붙임, 단서 병합
```
② 회사는 18세 이상의 여성을 … 동의를 받아야 한다. (2026. 8. 31. 신설)
③ 회사는 임산부와 18세 미만자를 … 근로 시키지 못한다. 다만, 다음 각 호의 어느
   하나에 해당하는 경우로서 … 그러하지 아니하다.
1. 18세 미만자의 동의가 있는 경우 (2026. 8. 31. 신설)
```

근거: 제16조제2항제2호, 제14조제3항·제4항

### 6.3 별표·서식 목록 (부칙 다음)

**정정 전** — 목록 자체가 없음

**정정 후**
```
[별표 제1호] 직장 내 성희롱 판단을 위한 기준의 예시 <○○○○. ○. ○. 개정>
[별표 제2호] 직장 내 괴롭힘 판단을 위한 기준의 예시 <○○○○. ○. ○. 개정>
```
제목은 검정, `< >`만 파란색. 개정일자를 알 수 없으면 자리표시로 두고 확인 요망.
개정 이력이 없으면 `< >`를 아예 붙이지 않는다.

근거: 제11조제1항·제3항, 제16조제4항

## 7. 이 지침의 한계

- 이 문서는 **표기·형식 점검**을 위한 것이다. 법령 저촉 여부, 상법·금융회사지배구조법 해석, 다른 사규와의 실질적 충돌은 **법무 검토와 소관부서 판단**이 필요하다.
- **글자색은 업로드된 문서에서 판별되지 않을 수 있다.** 색상 관련 지적은 원본에서 직접 확인하도록 안내한다.
- **다른 사규를 인용한 조문이 실재하는지는 그 사규 원문을 봐야 확인된다.** 인용 조문의 실재 여부는 단정하지 말고 확인 요망으로 남긴다.
- 「사규관리규정」이 개정되면 이 문서도 함께 고쳐야 한다. 두 자료가 어긋나면 **「사규관리규정」 원문이 우선**한다.
