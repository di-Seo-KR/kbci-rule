# 사규관리규정 개정 검토 — 서식 샘플·매뉴얼 대조

## 대조 자료
- **사규 샘플**: 성과관리규정 `[시행 2026.01.01.] [2025.12.24. 개정-2025-021]` (최신 서식 적용본)
- **담당자 매뉴얼 v1.1**(36쪽) / **사용자 매뉴얼 v1.1**(20쪽)
- **현행 사규관리규정** `[시행 2026.06.01.]`

## 결론 요약
- **서식·표기는 이미 잘 일치** ✓ (제30조의2 시행일자·문서번호 표기 ↔ 샘플 일치)
- 규정은 신구대비표·등록·전산시스템 등재·사규목차를 이미 보유 → **큰 누락은 없음**
- 개정 핵심 = **① 시스템·절차 ‘현행화’(사규관리시스템·전자결재·공포 명문화) ② 부록·안내사항·정본 개념 보강**

---

## 1. 서식·표기 — 일치 확인 ✓ (소소한 점만)
- 제30조의2 표기규칙 ↔ 샘플 `[시행 …] [… 개정-2025-021]` **일치** ✓
- 개정이력 표기 `(2025. 04. 01 본조 개정)` — 규정은 “0000. 00. 00.” 형식 요구 → **끝 마침표 누락**(‘04. 01’→‘04. 01.’) 등 **마침표 일관성**만 점검
- (샘플 자체 오류: 「성과관리규정」인데 제1조가 “이 **지침은**…” → 규정/지침 표기 불일치. **샘플 수정** 사항이며 규정 개정사항 아님)

---

## 2. ⭐ 시스템·절차 현행화 (핵심 개정 포인트)
| 현행 조문 | 실제 운영(매뉴얼) | 개정 검토 |
|-----------|-------------------|-----------|
| 제8조(등록)·제15조 “**전산시스템 등**에 등재” | **사규관리시스템**에 등록·관리·열람 | ‘전산시스템 등’ → **「사규관리시스템」** 명칭 명시(채널 일원화) |
| 제6·7조(기안·합의), 제9조(**시달**) | 시스템 등록 → **전자결재(시스템) 결재** → **공포** | **전자결재 연계** 절차 반영, ‘시달’ ↔ **‘공포’** 용어 정합 |
| 제7조① “**신·구 조문대비표** 작성” ✓ | 시스템에서 **신구대비표 생성** | 이미 규정화됨 → “시스템에서 생성” 문구만 보완 가능 |
| 제8조(별표)·제28·29·30조(별표·별지서식·별도) | **별표·부록·안내사항** 등록 운영 | **‘부록’·‘안내사항’** 개념이 규정에 미정의 → 정의/근거 신설 검토 |
| (없음) | 시스템 등재본 기준 운영 | **정본(正本) 조항 신설 검토** — “사규관리시스템 등재본을 정본으로 한다”(정책 확인 필요) |
| 제15조①(규정집 간행) | 시스템 상시 열람 | ‘규정집 간행’은 **임의(필요시)** 로 유지/완화 검토 |

## 3. 정의·개념 보강 검토
- **부록** : 시스템·매뉴얼에서 ‘별표·부록’으로 운영되나 규정 제2조 정의에 없음 → 정의 추가 검토
- **안내사항** : 사규별 안내 등록 운영 → 근거 조문 검토
- **공포** : 제9조 ‘시달’을 ‘공포’로 정의·통일(매뉴얼 용어와 일치)
- **정본(正本)** : 시스템 등재본의 효력 기준 명문화(광운대 벤치마크와도 부합)

---

## 4. 함께 반영 권장
- **한자식 표현 정비(법제처 확인분)** 를 이번 시스템 현행화 개정과 **동시 반영**하면 효율적
  (개폐→개정 또는 폐지, 시달→통보·공포, 견양→견본, 등사→복사, 당해→해당, 기타→그 밖의, 내지→부터·까지 등)
