# KBCI 「사규관리규정」 한자식 표현 정비안 (법제처 기준 적용)

- **대상**: 사규관리규정 [시행 2026. 6. 1.]
- **기준**: 법제처 「알기 쉬운 법령 정비기준(제10판 합본)」 — **권고안이 확인된 표현만** 순화

## 0. 적용 원칙
- **법제처 정비기준에 권고안이 있는 표현만** 순화합니다.
- 법제처 권고 목록에 **없는** 한자어(체상·체하, 갈음, 주지, 성문화, 자구, 체제, 광의·협의, 용도품 등)는 **그대로 유지**합니다.
- 법률 전문어(준용·구속력·간주·경과조치)도 유지합니다.

## 2. 문장 표현 — 법제처 권고 확인분 ✓
| 현행 | 순화 | 법제처 근거 |
|------|------|-------------|
| “~(이)라 함은 ~을 말한다” | “~(이)란 ~을 말한다” | 문장편(정의 규정): ‘함’=‘말함’ 서술어 중복 → ~란/이란 |
| “~에 의하여 / 의한 / 의할” | “~에 따라 / 따른 / 따를” | 용어편: 의하여→따라 |
| “~하여서는 아니된다” / “아니한” | “~해서는 안 된다” / “않은” | 하위규정 표기 권고 |
| “~에(도) 불구하고” | “~에도” | 용어편 |

## 3. 유지 — 법제처 미등재(변경하지 않음)
**체상(遞上)·체하(遞下)** · 갈음 · 주지(周知) · 성문화(成文化) · 자구(字句) · 체제(體制) · 광의(廣義)/협의(狹義) · 용도품 · 조제(調製) · 발하여진
→ 법제처 권고 목록에 없으므로 **그대로 사용** (체상/체하는 정상 용어)
※ 법률 전문어(준용·구속력·간주·경과조치)도 유지.

## 4. 주요 조문 적용 예시 (법제처 변경분만)
**제2조 1호** — ‘규정’**이라 함은** … **성문화된** 것을 말한다.
→ ‘규정’**이란** … **성문화된** 것을 말한다. *(‘성문화’는 유지)*

**제9조 ①** — 주무부서장은 **등록 필** 규정을 … 명의로**서 시달**한다.
→ 주무부서장은 **등록을 마친** 규정을 … 명의로 **통보**한다. *(조명 ‘시달절차’→‘통보 절차’)*

**제12조** — 규정의 제정·**개폐**의 내용을 … 철저히 **주지시켜야** 한다.
→ 규정의 제정·**개정·폐지** 내용을 … 철저히 **주지시켜야** 한다. *(‘주지’는 유지)*

**제7조 ④** — … 소관부서에 **회송한다**. 다만, … 조정되지 **아니한** 때에는 …
→ … 소관부서에 **돌려보낸다**. 다만, … 조정되지 **않은** 때에는 …

**제24조 ①1** — “… 하나씩 **체하하고** …” → **유지** (법제처 미등재어)
