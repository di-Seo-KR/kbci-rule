# 사규관리규정 정합성·현대화·경량화 검토

> 목표: 모호·상식불일치·난해·구시대 표현을 걷어내고 **경량화·현대화·정합성** 제고
> (※ 한자식 표현 정비(법제처)·시스템 현행화 검토는 별도 문서와 연계)

---

## A. 논리·정합성 오류 — 우선 수정
### A-1. ‘목(目)’ 위계 오류 (제18조·제20조) ★지적사항
- 제20조: “조에는 … **편·장·절·관·목**이 바뀌더라도 그 번호순을 바꾸지 아니한다”
- 제18조②③: 소분류 “**절·관·목**”, “**편·장·절·관·목**에 일련번호·제목”
- **문제**: 표준 위계는 〔편>장>절>관〕(조 위 묶음) / 〔조>항>호〕(조 아래)이며, 호 세분은 가·나·다/(1)(2)/(가)(나)(제23조). **‘목’은 조 위 묶음 단위가 아님**(원래 호 아래 최소 단위). → 제20조에서 ‘목’만 조 위 단위처럼 끼어 **항·호 누락과 정합성 불일치**.
- 게다가 이 규정은 실제로 ‘목’을 쓰지 않음(가·나·다로 세분) → **사문화**.
- **정비**: 제18조·제20조에서 **‘목’ 삭제 → ‘편·장·절·관’** 으로 통일.

### A-2. 효력순위 ‘중복+불일치’ (제5조 ↔ 제10조의2) ★
- 제5조②: 정관 → 이사회규정 → **경영협의회규정 → 직제규정** → 기타
- 제10조의2②: 정관 → 이사회규정 → **이사회 부의대상 규정 → 대표이사 전결규정** → 기타
- **문제**: 같은 ‘효력순위’ 조항이 둘이고 **위계 목록이 서로 다름**(정합성 오류). ①외규 우선 ③동일순위 신규정 우선 ④지침 효력까지 양쪽 **중복**.
- **정비**: **두 조를 하나로 통합**(현행 거버넌스 기준 단일 목록) → 경량화+정합성.

### A-3. 비문·오타
- 제9조①: “주무부서장은 등록 필 규정을 **규정은** 대표이사 명의로…” — 주어 중복 **비문** → 문장 정리.
- 제30조의2 ②2: “표시할 **있으나**” → “표시할 **수** 있으나” (오타).

---

## B. 모호·난해 — 명확화
- **제2조2호(지침 정의)**: “‘규정’ 이외에 …” 식의 **소극적·순환적 정의** → 지침의 적극적 정의로 보완.
- **제3조/제4조**: ‘잠정적·가변적’, ‘보편타당성’ 등 추상어 → 구체화 또는 축약.

---

## C. 구시대·중복 — 경량화 후보
- **제4조(규정화시 유의사항)**: 계속성·탄력성·균형성·적용성·능률성 — 추상 훈시 규정 → **삭제 또는 1개 항으로 축약** 검토.
- **제31조(문체) ↔ 제31조의2(표현)**: 내용 중복·구식 → **통합**.
- **제39·42·43조(인쇄서식·조제년월·일괄인쇄)**: 인쇄서식 중심 — 전산서식 시대에 비중 과다 → **현대화·축약**.
- **제15조(규정집 간행)**: 시스템 상시 열람 시대 → ‘간행’ 표현 완화/삭제 검토.
- **제45조(전산출력자료 관리)**: 잔액장·명세 등은 본 규정 범위와 거리 → 위치 적정성 검토.
- **제2장 작성기법(제18~37조)**: 입법기술 세부(전단·후단·단서·체상·체하·괄호·구두점 등)가 매우 상세 → **별도 ‘사규 작성지침’으로 분리** 시 본 규정 대폭 경량화 가능(광운대·경희대는 이 수준 아님).

## D. 시스템 정합성 (별도 검토 연계)
- ‘전산시스템 등’ → **「사규관리시스템」** 명시 / ‘시달’ → ‘공포’ / 부록·안내사항·정본 개념 보강.

---

## E. 표현·특수문자 일관성 ★
한 규정 안에서도 표기 기준이 뒤섞여 있어 통일이 필요합니다.
- **괄호류 혼용**: 「 」(홑낫표)·『 』(겹낫표)·" "(큰따옴표)가 혼용.
  - 정의어: 제2조 “규정”(큰따옴표) ↔ 제16조 「규정」(낫표) → **하나로 통일**
  - 별표: 『별표』(겹낫표) — 제36조는 「 」만 정의하고 『 』·" " 기준은 없음 → **사용 기준 명문화 또는 통일**
- **가운뎃점**: 제36조의2가 ‘ㆍ’(U+318D)로 적었으나 본문은 ‘·’(가운뎃점) 사용 → **표준 ‘·’로 문자 통일**
- **용어 혼용**: 제정·개폐 / 제·개폐 / 제정·개정·폐지, 신·구 조문대비표 / 신구대비표 → **용어 통일**
- **조문번호 표기**: ‘제10조’ ↔ ‘제 10 조의 2’(공백) → **‘제10조의2’로 통일**
- **날짜 표기**: 제30조의2는 ‘0000. 00. 00.’(2자리) 규정 → 그러나 본문·부칙은 ‘2026. **6. 1.**’, ‘1999. **10. 9.**’ 등 영(0) 미표기 → **자기 규정과 불일치**. 영점·마침표 통일
- **띄어쓰기 오류**: ‘운용할수’, ‘탄력성있게’(제4조) 등 붙여쓰기 오류 산재 → 맞춤법 점검
