## 2. 벤치마킹 시사점 — 채택 권장 ✅
- **규정 위계 명문화**(제5조) → 우리도 사규 체계(정관>규정>지침>세칙 등) 명확화
- **편성·제정형식 표준**(제6·7조) → 총칙/본칙/부칙, 장·절·조·항·호 표기 통일 → **시스템 본문 구조와 직결**
- **역할 분리**(제9조) 주관/관리/소관 → 사규 총괄(경영전략부)/소관부서 책임 구분
- **경미사항 전결**(제10조) 명칭변경·오타 정정 등 → 신속 처리(시스템 운영 효율)
- **입안서·신구조문대비표 서식**(서식1·2) → 우리 시스템의 **‘신구대비표 생성’·전자결재 연계와 정확히 부합**
- **제·개폐 절차 차등화 + 심의기구**(제12조)
- **규정대장·보존**(제13·14조) → 시스템 이력관리로 **대체·고도화 가능**

---

## 3. 내용 적정성 & 우리 적용 시 보완 ⭐ (가장 중요)
광운대 규정은 **종이/수기 시대 기반**이라 *사규관리시스템 운영 전제 조항이 없음*. 우리는 다음을 **신설**해야 함:
- ⭐ **시스템 등록·정본화** : 모든 사규는 사규관리시스템에 등록하고 **시스템 등재본을 정본(正本)으로 운영**
- ⭐ **전자결재 연계** : 제·개정·폐지 = 시스템 등록 → 신구대비표 → 전자결재(1·2차 승인) → 공포·시행
- ⭐ **공포·공지 현대화** : ‘사본 배부’(제13조) → 시스템 공지·게시
- ⭐ **현행화·정기정비** : 정기 점검·정비 주기 명시(광운대 규정엔 없음)
- **분류체계 반영** : 우리 **편(編) 분류체계**를 규정에 명문화(광운대엔 없음)
- **맥락 치환** : 학칙·대학평의원회·총장 → 우리 사규 위계·경영회의/위원회·대표이사·이사회 등

## 4. 알기쉬운 법령정비기준 관점 — 우리가 피해야 할 표현
| 광운대 표현 | 쉬운 말(우리 규정 적용) |
|-------------|------------------------|
| 개폐(改廢) | 제정·개정·폐지 (또는 개정·폐지) |
| 제규정(諸規定) | 각 규정 / 모든 규정 |
| (결재를) 득하여 | (결재를) 받아 |
| 수합하여 | 취합하여 / 모아 |
| 준거하여 | 근거하여 |
| ~라 함은 | ~란 (예: “주관부서라 함은” → “‘주관부서’란”) |
| 가제(加除) | 추가·삭제 |

- **만연체 정비** : 한 문장에 여러 사항(제1조 등) → **한 문장 한 내용**으로 분리
- **능동·명확** 표현 우선

## 5. 표기·정합성 점검
- ⚠️ **조문 번호 오류** : 제13조가 **2회 등장**(‘관리’ / ‘규정가제 삭제’) → 우리 작성 시 **조번호 정합성** 주의
- 부칙·서식 번호 표기 일관성 유지
- 한자식 용어의 표준국어대사전 부합·쉬운말 여부 점검
